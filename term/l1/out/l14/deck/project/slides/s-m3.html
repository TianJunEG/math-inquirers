One test can show a claim is false

CLAIM

An odd number plus an odd number is odd.

3 + 5 = 8. 8 is even. The claim is not always true.

Always, sometimes or never?

Math Inquirers Term 2 • Notice it. Test it. Explain why.

A new claim: odd plus odd is odd. Test 3 + 5 = 8, which is even, so the claim is not always true. One test that fails is enough to show that. Ask: is odd + odd always odd, sometimes odd or never odd? From our tests it looks never odd, but a few tests do not prove it. Say that a picture can show why. Answer so far: never odd (it was even each time we tried).
