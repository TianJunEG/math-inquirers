A table of outfits

Mei has 2 tops and 2 skirts. Each box is one outfit. How many outfits can she make?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example. A table has one row for each top and one column for each skirt, so each box is one outfit: top 1 with skirt 1, top 1 with skirt 2, top 2 with skirt 1, top 2 with skirt 2. 4 boxes, 4 outfits. Ask: what does each row stand for (a top); what does each column stand for (a skirt); how many boxes (4). The answer is on the next slide. Say: a table is a system: every top meets every skirt once.
