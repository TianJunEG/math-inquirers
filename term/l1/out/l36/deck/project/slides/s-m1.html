Count the new ones

A shakes hands with the others. How many handshakes does A make? Then B shakes hands with the ones not counted yet. How many new ones?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example, with the 3 children of Explore. A shakes hands with B and C: 2 handshakes. B has already shaken hands with A, so B makes only 1 new handshake, with C. C has no new handshake. 2 and 1 make 3. Ask: how many does A make (2); how many new ones does B make (1); how many does C make (0); how many in all (3). The answer is on the next slide. Say: each child counts only the new ones, so no handshake is counted twice.
