Altogether: add the prices

$10 + $2 = $12. Ben pays $12 altogether.

A sticker book $3 and a toy bird $13: $3 + $13 = $16.

Math Inquirers Term 3 • Notice it. Test it. Explain why.

The answers: $12 for the shoe and the button, $16 for the sticker book and the toy bird. Read them aloud and children tick their own work. Say: the gap uses take away or count up; altogether uses add.
