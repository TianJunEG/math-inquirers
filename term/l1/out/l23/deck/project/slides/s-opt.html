A game lasts 1 hour. Another game lasts half an hour. Both end at 8:30.

Write the time each game started. Who started first?

Math Inquirers Term 3 • Notice it. Test it. Explain why.

Optional, only if you are on time. Both games end at 8:30. The 1-hour game started at 7:30 and the half-hour game started at 8:00, so the 1-hour game started first. The longer a game lasts, the earlier it must start to end at the same time. Take two answers and move on. This links to Go further and the Investigation.
