Gaps can grow

The gap grows by 1 each time. So the next gap is 5.

Math Inquirers Term 1 • Notice it. Test it. Explain why.

A worked example of a pattern that does not have the same gap each time: 1, 2, 4, 7, 11. Read the gaps: 1, 2, 3, 4. The gap grows by one each time, so the next gap is 5 and the next number is 16. Ask: what would the gap after that be? Answer: 6. This is a worked example only, about a minute; Think harder uses a different pattern of the same kind.
