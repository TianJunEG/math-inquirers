Name each shape

Say the name of each shape. How many sides has each one?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Four shapes labelled A to D: A circle, B square, C rectangle, D triangle. Children say each name aloud on three, then how many sides each has (the circle has none that are straight; the square 4; the rectangle 4; the triangle 3). This is the holiday-course naming, taught again with pictures so a child who joins cold can follow. Ask: what is the same about the square and the rectangle (4 sides, 4 corners). The slide never shows the names. A child who is unsure touches each side with a finger.
