A CHILD IN ANOTHER CLASS SAYS

45 + 28 = 63.

I worked it out again the same way.

I got 63 again. So it must be right.

Do you agree? How could she check?

I think ... because ...

Math Inquirers Term 3 • Notice it. Test it. Explain why.

One minute of talk to the grown-up next to you, or to your screen. Volunteers first; a pass is always fine; never call a child by name to answer. Model answer: no, we do not agree. Doing it the same way again can make the same mistake again. A different way, such as taking away 28 from 63, gives 35, not 45, so 63 is wrong. The right answer is 73.
