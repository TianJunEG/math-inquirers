Add back to check

A child in another class writes 71 − 26 = 55.

Check: 55 + 26 = ?

Math Inquirers Term 3 • Notice it. Test it. Explain why.

Worked example. The child wrote 71 take away 26 equals 55. To check, add the 26 back to the answer: 55 and 26 make 81. We should get back to 71, but we get 81. So the answer is wrong. The right answer is 45, because 45 and 26 make 71. Ask: what is 55 plus 26 (81); do we get 71 (no); is the answer right (no). The answer is on the next slide. Say: if adding back does not give the number we started with, there is a mistake. Then the your-turn question: 60 take away 18 equals 52, check it. Answer: 52 + 18 = 70, not 60; the right answer is 42.
