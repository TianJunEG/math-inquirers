Explore: count the money

Start with the biggest coin. Count on.

Math Inquirers Term 3 • Notice it. Test it. Explain why.

Round 2, about 3 minutes, main room. Children count the money in each picture aloud, starting with the biggest coin, and may put the same coins on the table. Picture A is 50, 60, 70 (70 cents). Picture B is 20, 40, 60, 65 (65 cents). Ask: how many cents is picture A; how many is picture B. The totals are never on the slide. A child who counts each coin as 1 (3 coins) is asked: what is the number on the coin?
