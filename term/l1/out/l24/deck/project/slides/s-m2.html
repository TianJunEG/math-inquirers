Count the biggest first

50¢60¢70¢75¢

Biggest first. Then count on.

Math Inquirers Term 3 • Notice it. Test it. Explain why.

Worked example: a 50-cent coin, two 10-cent coins and a 5-cent coin. Start with the biggest, 50, then count on: 60, 70, 75. The total is 75 cents. Touch each coin as you say its count. Counting the biggest first is quicker and easier to keep track of than counting in any order. Children count along with you. Say: the answer is 75¢, with the cent sign.
