Math Inquirers Term 3 • Notice it. Test it. Explain why.

Show the table that children found in Explore: 1 triangle 3 sticks, 2 triangles 5, 3 triangles 7, 4 triangles 9, and an empty box for 5 triangles. We call the strips sticks in a table: the strips are our sticks. Say: a table keeps the numbers in order so that we can see how they grow. Children write the same table on their own paper. Ask: what goes in the last box (11, as we guessed). Confirm it: this is the answer to Explore round 3.
