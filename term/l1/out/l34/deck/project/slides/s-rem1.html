Warm-up: rows

Count the counters by rows. How many rows? How many in each row? How many in all?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Counting by rows (Term 2 Lesson 5, taught again). 2 rows with 3 counters in each row: 3 and 3 make 6. Ask: how many rows (2), how many in each row (3), how many in all (6). A child who is unsure points along each row. Your turn, no picture: 3 rows of 2; how many in all (6). Children answer aloud. No writing.
