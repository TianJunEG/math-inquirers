Doubles

A double is the same number twice. Double 3 is 3 and 3 again. Double 5?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Doubles (Term 2 Lesson 3, taught again). Double 3 is 3 and 3 again: 6. Ask: what is double 3 (6), what is double 5 (10). A child who is unsure holds up 5 fingers on each hand. Your turn: double 4 (8). Say: each time we double, the number of layers doubles; we use that later. Children answer aloud. No writing.
