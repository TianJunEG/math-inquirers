Math Inquirers Term 1 • Notice it. Test it. Explain why.

Ask: which tool for 62 take away 59, and which for 62 take away 20? Answer: count up for the first (3), take away for the second (42). This is the rule of thumb the Go further page asks children to explain. Both tools give the same answer; choosing is about being quick and being right.
