Is the grid finished?

Check every row. Check every column. Is it correct?

Math Inquirers Term 3 • Notice it. Test it. Explain why.

The check move: a grid is not finished until every row and every column has one of each. Rows: circle, square, triangle (yes); square, triangle, circle (yes); circle, triangle, square (yes). Columns: circle, square, circle (no: two circles); square, triangle, triangle (no); triangle, circle, square (yes). So the grid is not correct. Ask: do all the rows follow the rule (yes), so are we done (no, we must check the columns too). Children say which column has a repeat. Never check only the rows.
