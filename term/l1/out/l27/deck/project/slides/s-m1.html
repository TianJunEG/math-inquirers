The rule

THE RULE

One of each in every row.

One of each in every column.

Math Inquirers Term 3 • Notice it. Test it. Explain why.

Name the rule and show a finished grid. A row goes across, a column goes down. Read each row of the grid on the slide: square, circle, triangle; triangle, square, circle; circle, triangle, square. Then each column: square, triangle, circle; circle, square, triangle; triangle, circle, square. Every one has one of each. Also confirm the answer to Explore round 3: with the top row circle, square, triangle there were 2 grids. This grid has a different top row, so it is a new one. Say: a grid like this is a puzzle square, and every empty box in a puzzle has a reason.
