BOX a IS THE MIDDLE BOX

Its row has a square.

Its column has a circle.

Math Inquirers Term 3 • Notice it. Test it. Explain why.

The worked elimination. Box a is in the middle of the grid. Its row has a square, so box a is not a square. Its column has a circle, so box a is not a circle. It cannot be a circle or a square, so it must be a triangle. Say the move slowly: if it is not this and not that, it must be the other one. Ask: could it be a square (no, the row has a square); a circle (no, the column has a circle); so what is left (triangle). Children test with their tiles on mat 1 if they set up the same grid.
