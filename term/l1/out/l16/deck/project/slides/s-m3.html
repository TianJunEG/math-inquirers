A last digit can tell you if a number is in a table.

Math Inquirers Term 2 • Notice it. Test it. Explain why.

Last digits make a pattern. The 5s end in 5 or 0; the 10s always end in 0; the 2s end in 0, 2, 4, 6 or 8. Ask: is 35 in the 5s table (yes, it ends in 5)? Is 28 in the 5s table (no, it ends in 8)? Say that the last digit helps us test; a few tests do not prove a rule for every number, but the jumps show why.
