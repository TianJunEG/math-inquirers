Which question can it answer?

1How many bikes are there?

2Which toy does Siti like best?

3How many more balls than cars are there?

Which questions can the graph answer? Think about each one.

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example. A graph can answer only questions about what it shows. Read the three questions one at a time. Ask: can the graph answer this one? Question 1 yes (4). Question 2 no: the graph shows the toys in the box, not who likes which. Question 3 yes (2). The answer is on the next slide. Say: before we draw a graph, we choose a question the things can answer. If we want to know what people like, we ask people and sort their answers.
