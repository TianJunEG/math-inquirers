Read the graph

How many more balls than cars? How many toys in all? Which kind has the fewest?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example. Children read the graph from the last slide. Ask: how many more balls than cars (2); how many toys in all (12); which kind has the fewest toys (cars). The answer is on the next slide. Say the fixed question forms every time: how many more ___ than ___; how many in all; which has the fewest. A child who answers 8 for how many more has added: say, more means the extra pictures, so match the rows.
