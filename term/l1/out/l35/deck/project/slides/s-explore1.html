Explore: the odd card

1Take your pair cards. Keep each row of 4 together.

2Lay out set 1, the top row, in a line.

3Three cards are alike. Find the odd one.

What is different about the odd card? Say it in a whole sentence.

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Round 1, about 6 minutes. Each child has the 12 pair cards cut out beforehand; the page has three rows, and each row is one set of 4: three alike and one different. Set 1 (top row): apples and one cookie. Set 2 (middle row): ladybirds and one spider. Set 3 (bottom row): cups and one jar. Children lay a set in a line, find the odd card and say what is different, then do the same for sets 2 and 3. About 2 minutes a set. Do not tell which card is odd. Ask: which card is the odd one; what is different about it. Accept any true thing: it is a different thing, it has more legs, it has a lid. Nobody holds cards up to the camera: children say it aloud and show fingers. A child with no cards draws 4 small pictures on paper. Answers on the next slide.
