The odd one out

Four tiles are alike. One is the odd one out. Which one? What is different?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example. Five circles with stripes. Four are the same size and tile C is bigger, so C is the odd one out and the difference is size. Ask: what do four of them have in common (the same size), which tile is the odd one out (C), what is different about it (size: it is bigger). The answer is on the next slide. Say: check one thing at a time: shape, number, size, pattern, turn.
