The missing piece

Look across. Then look down. Which tile goes in the box with the question mark?

Math Inquirers Term 4 • Notice it. Test it. Explain why.

Worked example. A 2 by 2 pattern: across, the pattern changes from plain to stripes; down, the shape changes from circle to star. So the missing tile is a star with stripes, option B. Option A is a star but plain (the pattern is wrong), option C has stripes but is a circle (the shape is wrong), option D is a star with stripes but small (the size is wrong). Ask: what changes when we go across (plain to stripes); what changes when we go down (circle to star); which tile goes in the box (B). The answer is on the next slide.
