Math Inquirers Term 4 • Notice it. Test it. Explain why.

Children check their own sets. Set 1: the cookie, not an apple. Set 2: the spider, with eight legs (the ladybirds have six). Set 3: the jar, with a lid. Say: all of these are different in one thing, what it is. Ticks only. Do not name any child.
