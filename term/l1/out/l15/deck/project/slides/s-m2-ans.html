× means groups of: the first number is how many groups.

5 groups of 2: 2 + 2 + 2 + 2 + 2 = 10, so 5 × 2 = 10.

Math Inquirers Term 2 • Notice it. Test it. Explain why.

The sign × is a short way to write groups of. 4 × 3 means 4 groups of 3. Read it as 4 groups of 3 (or 4 times 3). The first number is how many groups; the second is how many in each group. Only the worked row is on the question slide: 5 groups of 2 is asked aloud. Children say the total first; the answer comes on the next slide. Accept 3 × 4 as a correct way to write the same total (we meet this in the array); frames in the workbook use groups first. (answer shown after the children have answered)
