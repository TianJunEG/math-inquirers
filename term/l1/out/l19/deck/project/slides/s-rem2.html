The same number twice

Two plates with the same number of counters.

Math Inquirers Term 2 • Notice it. Test it. Explain why.

Two plates with the same number of counters. Twelve counters in all. Ask: what is 5 + 5 (10); box + box = 8, the same number twice (4); 7 + 7 (14). Children answer aloud. A child who is unsure deals counters one at a time onto two plates, or uses fingers on two hands. The same number twice is a double: it comes back with the hearts in Explore.
