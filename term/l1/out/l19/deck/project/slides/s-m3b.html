A number that works in one line may not work in another, so we check every line. Line 1: 5 + 5 + 7 = 17. Line 2: 5 + 7 = 12. Both match. Ask: what would we think if line 1 did not match (the numbers are wrong, try again). Link to the Think harder question where a friend gives numbers that work in only one line.
