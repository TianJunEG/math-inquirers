# Home practice, parent summary and online practice audit: Lesson 10 (Story Steps: Read It Twice)

Second-round independent audit, role HOME_PARENT_PRACTICE. Files audited: `term/l1/out/l10/L10_Home_Practice.pdf`, `L10_Parent_Summary.pdf`, `out/l10/practice/` (key `t1l10`). Source data: `term/l1/lessons/l10.json`.

## Verdict: Ready after minor fixes

Home sheet, parent summary and online practice are correct and well pitched. The parent-facing material around the end-of-term check has real gaps: a retention statement that disagrees with the privacy notice, a "took the check" sentence that is not true for every child, and no clear route for how the sheet reaches the family.

Counts: lesson-specific 0 High, 5 Medium, 3 Low. Shared (same in all five lessons): runner R1 to R12 = 0 High, 4 Medium (R1 to R4), 8 Low; print/parent P1 to P6 = 0 High, 3 Medium (P1 to P3), 3 Low.

## Method (what was actually done)

- Read first: AUTHORING.md, WORDING_GUIDE.md, owner_decisions.md, the first-round `WORKBOOK_AUDIT_L10.md` and `FIXES_L10.md` (not repeated here), `levels/reccues.js`, `tutor/README.md`, the project rubrics (severity scale reused: High = wrong maths / unsafe / unusable, Medium = misleading, ambiguous, impractical or inconsistent, Low = polish).
- Printed pieces: `out/l10/L10_Home_Practice.pdf` (2 pages) and `L10_Parent_Summary.pdf` (1 page) rendered with pdftoppm at 60 and 80 dpi and viewed; ink margins measured from the rendered pixels; text extracted with pdftotext; all five home answers re-computed by hand and in Python.
- Online practice: `out/l10/practice/` served as a static root (the runner uses root paths, see R1) and driven with Playwright 1.56.0 / Chromium 141 at 375x740 (phone) and 1280x800 (laptop). Every item of every tier was opened and its authored answer typed or chosen (all accepted). Every templated item was then re-run in the browser with the template variables forced to 8 random combinations (route interception of the data file) and the answer typed from the lesson's own brute-force `ORACLES` in `verify/l10_checks.py`: result below. All template combinations were also enumerated in Python for wording (singular/plural, unfilled placeholders), range (0 to 100, whole) and every `a op b = c` written in the steps.
- Request log, console log, `localStorage` content, DOM before checking, keyboard order and focus, typed-answer experiments (spaces, leading zeros, units, words, number sentences, commas) were captured.
- AUDIT ONLY: no lesson, tool, template or output file was edited. The runner file is byte-identical in all ten lessons (`cmp` against `practice/public/practice.js` and `index.html`), so runner findings R1 to R12 are shared; they are repeated here so this file stands alone. Lesson-specific findings use the prefix L10-.
