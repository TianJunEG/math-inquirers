# Wording review: Lesson 4

Format: old -> new, then a one-line reason. Strings are exact; (xN) = text appears in N places (slide, script, key).

- "Which number is it on now? How do you know?" -> "Which number is it on now? Write how you know." (x2). one command per sentence: the reason is a Write command.
- "Which number is it on now? Write the number, and how you know." -> "Which number is it on now? Write the number. Then write how you know.". tutor read-aloud matches slide, one job per sentence.
- "Count in 10s. Colour 10, 20, 30, and keep going to 100. Then fill in the blanks." -> "Count in 10s. Colour 10, 20, 30 and keep going to 100. Then fill in the blanks.". stray comma before 'and'.
- "Count in 5s. Colour 5, 10, 15, and keep going to 100. Then fill in the blanks." -> "Count in 5s. Colour 5, 10, 15 and keep going to 100. Then fill in the blanks.". stray comma before 'and'.
- "They make a line going ___ (across or down)" -> "The colours make a line going ___ (across or down).". 'They' had no clear noun.
- "Every number I coloured ends in ___ or ___" -> "Every number I coloured ends in the digit ___ or ___.". blank had no unit; say the digit.
- "Every number I coloured ends in ___" -> "Every number I coloured ends in the digit ___.". blank had no unit; say the digit.
- "They make ___ lines going down" -> "The colours make ___ lines going down.". 'They' had no clear noun; blank now follows 'make' in a full sentence.
- "Count in 2s. Colour 2, 4, 6, and keep going to 30. Write the last digits you see." -> "Count in 2s. Colour 2, 4, 6 and keep going to 30. Look at the last digit of each number you coloured.". 'the last digits you see' was vague: say what to look at.
- "The last digits are ___, ___, ___, ___, ___" -> "The 5 different last digits are ___, ___, ___, ___, ___.". say there are 5 different digits so the child does not write all 15.
- "Question 4: count in twos and colour 2, 4, 6 up to 30, then write the last digits you see." -> "Question 4: count in twos and colour 2, 4, 6 up to 30. Look at the last digit of each coloured number. Write the 5 different last digits.". tutor read-aloud matches the new question.
- "a is ___" -> "Square a is ___". 'a is ___' repeated the label and was not a sentence.
- "b is ___" -> "Square b is ___". same.
- "c is ___" -> "Square c is ___". same.
- "Siti counts in 5s: 5, 10, 15, 20, 26, 30, 35. One number is wrong. Circle it. Write the number she should have said. How do you know?" -> "Siti counts in 5s: 5, 10, 15, 20, 26, 30, 35. One number is wrong. Circle it. Then fill in a and b.". hidden second and third question: now one command, then parts a and b.
- "She should have said ___" -> "a) She should have said ___.". part a asks for the right number.
- "Question 6: Siti counts in fives. Which number is wrong?" -> "Question 6: Siti counts in fives. Which number is wrong? Circle it. Then write what she should have said, and how you know.". tutor read-aloud now says all the jobs.
- "Start on 27 on your 100 square. Go down 3 rows. Which number do you land on? How do you know?" -> "Put a counter on 27 on your 100 square. Move it down 3 rows. Which number does it land on? Write how you know on the lines.". 'Start on' and 'Go down' did not say what to do with the counter; 'How do you know?' is now a Write command.
- "I land on ___" -> "It lands on ___.". matches the counter in the question.
- "A counter starts on 14. It goes down 2 rows, then right 3 squares. Which number does it stop on? Show each step." -> "A counter is on 14. It moves down 2 rows. Then it moves right 3 squares. Which number does it land on? Write each step on the lines.". two moves in one sentence; 'Show each step' did not say how; 'stop on' changed to 'land on' like T1.
- "It stops on ___" -> "It lands on ___.". same word as the question.
- "Mei counts in 2s up to 30: 2, 4, 6 and on. Ali counts in 5s up to 30: 5, 10, 15 and on. Which numbers do they both say?" -> "Mei counts in 2s up to 30: 2, 4, 6, 8 and so on. Ali counts in 5s up to 30: 5, 10, 15, 20 and so on. Write the numbers they both say.". 'and on' is not English; question turned into a command.
- "In this chain, each number is the two numbers before it added together: 2, 6, __, 14, 22, __. Fill in both blanks. What is the rule in your own words?" -> "Here is a number chain: 2, 6, ___, 14, 22, ___. After 2 and 6, each number is the last two numbers added together. Fill in both blanks. Then write how you found the first blank.". the rule was told AND asked for; the first two numbers were not exempted; ask for the working instead.
- "8 and 36 (add the two numbers before)" -> "8 and 36 (2 + 6 = 8, and 14 + 22 = 36)". answer matches the new question.
- "Two rules are mixed in one list: 5, 50, 10, 45, 15, 40, __, __. Write the next two numbers. Then say what the 10th number is." -> "Two patterns are mixed in one list: 5, 50, 10, 45, 15, 40, ___, ___. Write the next two numbers. Then write the 10th number in the list.". 'rules' to 'patterns' (word used all lesson); 'say' to 'write' for a written answer.
- "Look at four squares in a block: 34 and 35 on top, 44 and 45 below. Add 34 + 45. Then add 35 + 44. What do you notice? Try two more blocks. Does it always work? Say why." -> "Look at this block of 4 squares. Fill in a to d.". six questions in one paragraph: now parts a to d.
- "(no parts)" -> "a) Add the two yellow numbers: 34 + 45 = ___ / b) Add the other two numbers: 35 + 44 = ___ / c) What do you notice? / d) Try two more blocks ... Write why.". G3 parts added so each job is numbered; the colours match the picture.
- "Use the 100 square on your kit page. Colour 3, 6, 9, 12 and 15. Where does each one sit?" -> "Use the 100 square on your kit page. Colour 3, 6, 9, 12 and 15. Look at where the colours are.". 'Where does each one sit?' had no clear answer.
- "Keep going to 30. Do the colours make a column like the 10s? What shape do you see? Look at 33, 36 and 39: what do you notice?" -> "Keep going to 60, in 3s. Do the colours make a column like the 10s? Write what shape you see. Then look at 33, 36 and 39. What do you notice?". text said colour to 30 but then asked about 33, 36 and 39 (picture/text mismatch); look_for already said 60.
- "because a row has 10 squares and 10 is not a number we count in 3s." -> "because a row has 10 squares and 10 is not said when we count in 3s.". 'a number we count in 3s' was clumsy.
- "Ali says: counting in 5s makes one column on the square, just like counting in 10s. Do you agree? Use the 100 square to explain." -> "Ali says: counting in 5s makes one column on the square, just like counting in 10s. Is Ali right? Use the 100 square to show why.". 'Do you agree?' is abstract for 6-year-olds.
- "Do you agree? Use the 100 square to explain." -> "Is Ali right? Use the 100 square to show why.". slide matches the question.
- "Ali says: counting in fives makes one column on the square, just like counting in tens. Do you agree? Use your 100 square to explain." -> "Ali says: counting in fives makes one column on the square, just like counting in tens. Is Ali right? Use your 100 square to show why.". tutor read-aloud matches.
- "A counter is on 26. It moves down 1, then right 1." -> "A counter is on 26 on the 100 square. It moves down 1 square. Then it moves right 1 square.". 'down 1' had no unit and was two moves in one sentence.
- "Down 1: ___" -> "After going down it is on ___". clearer than a bare label.
- "Then right 1: ___" -> "After going right it is on ___". clearer than a bare label.
- "Mei counts in 2s. She says 25. Is Mei right? Say why." -> "Mei counts in 2s: 2, 4, 6, 8 and so on. She says she will say 25. Is Mei right?". counting in 2s from 1 would say 25, so the start was missing (two possible answers); the reason is in the blank.
- "Count in 2s: 2, 4, 6, 8, ___. Will you say 17? Write yes or no, and why." -> "Count in 2s: 2, 4, 6, 8, ___. (a) Write the next number. (b) If you keep going, will you say 17? Write yes or no, and why.". two questions hidden in one line: now (a) and (b).
- "Find a calendar. Pick three dates. For each date, look at the date straight below it. How much more is it? Is it the same every time? Why do you think so?" -> "Find a calendar. Pick three dates that are not in the last row. Look at the date straight below each one. (a) How much more is it? (b) Is it the same every time? Write why.". four questions in a row: now (a) and (b); last-row dates have nothing below.
- "Will 37 get a counter? Will 60?" -> "Counting in 2s: will 37 get a counter? Will 60?". the question did not say which counting.
- "The counters make a ___." -> "The counters make a line going ___ (across or down).". blank had no unit; same sentence as S1.
- "10s end in 0." -> "Counting in 10s: every number ends in 0.". '10s end in 0' is not a sentence.
- "5s end in 0 or 5." -> "Counting in 5s: every number ends in 0 or 5.". same.
- "2s end in 0, 2, 4, 6 or 8." -> "Counting in 2s: every number ends in 0, 2, 4, 6 or 8.". same.
- "Say 10 more. Think: one row down." -> "Say the number that is 10 more. Think: one row down.". 'Say 10 more' was clipped.
- "What if each row had only 5 numbers?" -> "Here is a square with only 5 numbers in each row.". 'What if ... had' is a conditional too hard to read; present tense for a puzzle.
- "A counter is on 8. It moves down one row. Which number is it on?" -> "A counter is on 8. It moves down 1 row. Which number is it on?". digit for a number (same as all other questions).
- "Hide a number on the 100 square. Write two clues, like: it is in the 5s, and it is in the third row. Give it to your grown-up to find." -> "Hide a number on the 100 square. Write 3 clues, like: you say it when you count in 5s; it is in the third row; it is not in the 10s. Give them to your grown-up to find the number.". two clues left two answers (25 and 30); 'in the 5s' was unnatural; three clues leave exactly one number.
- "Recording: pause. Hide a number on the square and write two clues for a grown-up to find." -> "Recording: pause. Hide a number on the square and write 3 clues for a grown-up to find.". matches.
- "No single answer. Check that the clues fit the hidden number and fit only one number (in the 5s and third row gives 25 and 30; a third clue is needed)." -> "Many answers are right. Check that the clues fit the hidden number and fit only one number. The example clues (counting in 5s, third row, not in the 10s) give 25 only.". example now has exactly one answer; open question says so.
- "Hide a number on the 100 square and write 3 clues for your grown-up (for example: it is in the 5s, it is between 40 and 60, it is not in the 10s). Check that only ONE number fits." -> "Hide a number on the 100 square. Write 3 clues for your grown-up. For example: you say it when you count in 5s; it is more than 40; it is less than 50. Check that only ONE number fits.". the example clues left two numbers (45 and 55), which broke the 'only ONE' rule; 'in the 5s' and 'between 40 and 60' were unnatural or arguable.
- "List the numbers that fit the first two clues. Cross out any that break clue 3." -> "List the numbers that fit the first clue. Cross out any that break clue 2 or clue 3.". steps match the new example.
- "Exactly one number should be left. For example: in the 5s, between 40 and 60, not in the 10s: 45 and 55 fit the first two clues, so you need one more clue, such as the tens digit is 5." -> "Exactly one number should be left. For example: counting in 5s, more than 40 and less than 50 leaves only 45.". steps match the new example.

- "30 and 5 more is 35." -> "5 more than 30 is 35.". '30 and 5 more is 35' is not natural: '5 more than 30 is 35'.

- "A counter is on 8. It moves down 3 rows. Which number is it on?" -> "A counter is on 8 on the 100 square. It moves down 3 rows. Which number is it on?". the square was not named.
- "A counter is on {n}. It moves down {r} rows. Which number is it on?" -> "A counter is on {n} on the 100 square. It moves down {r} rows. Which number is it on?". same.
- "The gaps grow by 1. What number comes next?" -> "The gaps grow by 1 each time. What number comes next?" (x2). 'grow by 1' needs 'each time'.
- "Mei counts in 2s up to 30. Ali counts in 5s up to 30. How many numbers do they both say?" -> "Mei counts in 2s from 2 up to 30. Ali counts in 5s from 5 up to 30. How many numbers do they both say?". no start given: counting in 2s from 1 gives different numbers.
