# Level 3 term-time year plan (ages 8-10, builds on Primary 3)

Status: plan only, no lessons written. 4 terms x 9 lessons x 90 minutes = 36 lessons, online, groups of up to 8, for a different group from the holiday course. Sources read: `p3/SPEC.md`, `p3/content/*`, `p3/budget.json`, `docs/audit/audit_p3.md`, `gifted_p3.md`, `moe_alignment_p1_p3.md`, the three `intl_mapping_*` files, `docs/gifted_research.md`, `docs/levels_and_placement.md`, `docs/sasmo/g1_analysis.md`. **No `docs/sasmo/g3_*` file existed when this was written**, so SASMO points below are inferred from the Grade 1 analysis (a different grade) and are marked [UNVERIFIED] for Grade 3.

## 1. Design principles

1. **A year in four arcs.** T1 Number and tools (adapted holiday lessons, one careful pass over every P3 strand). T2 Calculation with understanding, money, data, patterns. T3 Measurement, shape, space and modelling. T4 Reasoning and structure, then a showcase. Terms 2-4 each end with a project or showcase lesson (T1 ends with the check in the buffer week), so the year rises from "learn the idea" to "use it on something open".
2. **Spiral on purpose, not by repeating.** Every strand returns at least twice in a new setting (e.g. fractions: T1 wall, T2 number line and simplest form, T4 fractions in measures). A spiral lesson always opens with a 10-minute "Remember" warm-up from an earlier term (two items from the last term, one from two terms back), so a child who joins at T1 and stays gets retrieval practice built in. Spiral reuse is listed in s4.
3. **Problem solving is taught as a ladder of named moves**: T1 draw it / list it / guess and check; T2 table, pattern, make a simpler problem; T3 bar model, work backwards, cut and rearrange; T4 cases, count systematically, argue by contradiction ("why can't it be...?"). Each lesson names one move and the tutor guide shows it.
4. **Inquiry grows term by term.** T1 children explain a result they found. T2 they design a small survey or shop. T3 they plan under constraints (budget, area). T4 they pose problems for others and defend a method. Each term's last lessons are open tasks with no single answer path.
5. **Tiers (owner principle, neutral labels).** Start here = core a child can approach before the lesson (objects, drawing, counting, guess-check, skills from the level below). Think harder = the idea taught in the lesson, in a new setting. Go further = mastery plus extension (multi-step, generalise, justify, pose). Labels are never shown as ranks or "ability" groups; every child tries Start here, then picks. Worksheet slot is only about 15-18 working minutes (timing audit), so 5-6 questions per lesson, rest "if time".
6. **Honest scope.** Enrichment alongside school, not a replacement: it does not teach every school skill to speed (written-algorithm fluency, mental-arithmetic speed). No claim of "MOE-aligned", "GEP preparation" or SASMO preparation. Real contest papers are private-paper material: refer by tag only, never copy; problems here are original. Term-time pacing follows a typical school order only loosely (schools differ) [UNVERIFIED for any single school].

## 2. Term-by-term plan

Key: S = Start here, T = Think harder, G = Go further. "MOE" = Primary 3 strand (2021 syllabus). "ABOVE" = MOE puts it in a later year (preview). "NOT IN" = enrichment, no MOE outcome. Lesson numbers run 1-36.

## 5. Assessment and progress

**End-of-term check (10 questions, about 25 minutes, in the buffer week, no ranking).** Q1-4 retrieval of the term's core skills (Start here level, one each from the first four strands taught). Q5-7 apply in a new setting (Think harder level). Q8 explain why in words or a drawing. Q9 an open problem with more than one valid answer. Q10 a spiral item from two terms back. Each question is tagged by strand, so the tutor sees which strand needs another look, and the result is shown as a strand profile, not a mark out of 10. The check also tells a new joiner at T2-T4 which catch-up pages to use.

**Parent report line per term (observations, not outcome claims).**
- T1: "This term [Name] learned to [explain a number puzzle using place value and draw a bar model]; next we will practise [one strand from the check] while we move to calculation with understanding."
- T2: "[Name] can now [say why a written method works and read a graph's scale]; a thing to practise at home is [one strand]."
- T3: "[Name] tried [measurement and spatial tasks] and [chose a bar model without prompting / needed hints]; the term project shows [one noticed strength]."
- T4: "Across the year [Name] [moved from ... to ...] in [one thinking move]; for next year, [one suggestion: join Level 4 / revisit one strand]."
