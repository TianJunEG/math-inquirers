# Inquiry skills: explicit and intentional (design, draft)

Owner direction (2026-10-24): inquiry skills must be explicit and intentional. Parents, tutors and children should be able to see which skill is being practised, when, and how.

## 1. The six named inquiry habits (one set, all levels)
Built on the existing Toolbox Card tools so there is one vocabulary, not two.

| Habit | Child-friendly phrase | Card tools it draws on |
|---|---|---|
| Notice | "What do I see?" | Spot the pattern, Draw it |
| Wonder | "What could I ask?" (make a question or a 'what if') | Make a table |
| Try | "Let me test it" (examples, guess and check, small cases) | Guess and check, List every way |
| Check | "Does it always work?" (test a second case, work forwards/backwards) | Work backwards |
| Explain | "Here is why" (say or write the reasoning) | all |
| Look back | "What did I learn? What would I change?" | Look-back line (spine.json `lookback`) |

(Final names to be reconciled against levels/spine.json `tools`; wording by band A/B/C as the spine does.)

## 2. What "explicit" means in practice
1. **Lesson plan:** every lesson names ONE focus habit (and at most one supporting). Tutor guide front page states it with the 1-line teaching move.
2. **On the slide:** a habit badge on the opening slide and on the look-back slide; the same icon every time.
3. **Workbook:** each lesson has at least one question tagged with the habit (e.g. "Check it: try a second case"), not only the investigation.
4. **Online practice:** at least one "explain your thinking" item per lesson (self-checked, not auto-marked) tagged with the habit.
5. **Tutor move:** a scripted prompt per habit (e.g. Check: "Will it work with a different number? Test it.") and a "don't give the answer first" rule for the focus step.
6. **Progression:** the habit set is fixed across levels; difficulty and independence rise by band (A: tutor models, B: shared, C: child leads).
7. **Evidence:** the report records which habits were practised and one observed example per term, in the tutor's words. It records evidence, not a grade or a promise.

## 3. Claims wording (see lawyer question list)
Safe: "Every lesson practises inquiry habits: noticing, wondering, trying, checking, explaining and looking back."
Avoid: "will acquire / will master / guaranteed", and anything implying a result after one class.
