# Levels named by age, and placement by diagnostic
Typical age in the year a child finishes each school level (Singapore):
| Program level | Name on pages | For children finishing |
|---|---|---|
| P1 | Ages 7-8 | Primary 1 |
| P2 | Ages 8-9 | Primary 2 |
| P3 | Ages 9-10 | Primary 3 |
| P4 | Ages 10-11 | Primary 4 |
| P5 | Ages 11-12 | Primary 5 |
| P6 | Ages 12-13 (Maths + coding bridge) | Primary 6, after PSLE |
Pages show the age name first and the school level in brackets, e.g. "Ages 9-10 (finishing P3)".
## Placement
1. Parent takes the free 30-minute diagnostic for the level matching their child's age.
2. Result: 70% or more = enrol at that level. 40-69% = enrol at that level; tutor note that support may help (or choose one level down). Under 40% = recommend one level down.
3. A child may also try the diagnostic one level up if it was too easy (90%+).
4. Parent has the final say; the level can be changed before lesson 1 at no cost. Same price at every level.
5. Ages 7-8 is the lowest level; weaker learners there start with the free taster and a tutor chat.
