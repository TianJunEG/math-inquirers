## What changed (23 Oct 2026, owner decision COINS-FIX-SIZE)
Coin pictures now follow the real sizes of the current coins (MAS: 5c 16.75, 10c 18.5, 20c 21.0, 50c 23.0, $1 24.65 mm), drawn at 0.80 of real size. Notes are drawn 2:1 and bigger for higher values ($2 < $5 < $10, from the real 126 x 63, 133 x 66, 141 x 69 mm). Coins and notes are not drawn at the same scale as each other. Teacher notes say "Pictures are not actual size." Sources and numbers: `docs/school_books/coin_note_specs.md`. The art is still original (no real designs). Real size reference for the check: a $1 coin should look about 1.47 times the width of a 5c coin (24.65 / 16.75); a $10 note is 1.12 times as wide as a $2 note.
