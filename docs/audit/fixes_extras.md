## Notes
- Question banks: all Core / Think Harder / Challenge questions and answers copied from each level's qbank; a self-check confirms every question and answer appears in the built pages.
- Email packs: parent text uses parent_side.json; tutor emails use deck links from outputs/deck_urls_all.json (P5 from deck_urls_p4_p6.md). P5 L9 and L10 decks are empty shells, so those links show a placeholder.
- Tasters: real Lesson 1 sheet (questions 1 to 4), answers from the lesson key, tutor notes from lesson 1 content and script. The 5/8/5/9/3 minute split of the 30 minutes is new (a planning choice, not maths).
- What Learners Get: price lines reused from P1 (S$650 / S$500 intro, to confirm); workbook page count read from each level's workbook PDF.
- Not built: Word (.docx) versions (P1 also has them); PDFs only.
