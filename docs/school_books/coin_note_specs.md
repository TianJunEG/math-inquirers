# Coin and note specifications used for the booklet art

Owner decision COINS-FIX-SIZE (docs/terms/owner_decisions.md, 23 Oct 2026): coin pictures follow real Singapore coin proportions as closely as the specifications allow; banknote pictures are 2:1 and bigger for higher values; the teacher notes say "Pictures are not actual size." The art stays original (invented symbols, no real designs). Only the dimensions below are copied (a fact, not a design).

## Sources (read 23 Oct 2026)

- MAS, Circulation Currency: Coins, https://www.mas.gov.sg/currency/circulation-currency/circulation-currency-coins (the current 2013 "Iconic" series: table of material, weight, diameter).
- MAS, Circulation Currency: Notes, https://www.mas.gov.sg/currency/circulation-currency/circulation-currency-notes (Portrait series sizes).
- Cross-checks: Wikipedia "Singapore dollar" (coin table 16.75 / 18.50 / 21.00 / 23.00 / 24.65 mm; note table in mm); Wikipedia "Singapore Portrait Series currency notes"; MAS media releases 2005 ($2 polymer) and 2007 ($5 polymer) which state the polymer notes have the same size as the paper notes.

Correction: the earlier art used 16.2 / 18.5 / 21.4 / 24.7 / 24.65 mm. Those figures are from older (pre-2013) coin series: the old 20c was 21.36 mm and the old 50c was 24.66 mm. Only the 10c and $1 values were right. The current 50c (23.00 mm) is much closer to the 20c (21.00 mm) than the old 50c was.

| Note | Size (mm), width x height | Ratio |
|---|---|---|
| $2 | 126 x 63 | 2.00 : 1 |
| $5 | 133 x 66 | 2.02 : 1 |

Paper and polymer notes share these sizes (MAS 2005 and 2007 releases). The larger notes ($50 and up) are not drawn in these booklets.

## How the art uses them

- Coins: diameter = real diameter x 0.80 in P1 and P2 pages (5c 13.4 mm, 10c 14.8, 20c 16.8, 50c 18.4, $1 19.7 mm). In the colour-by-code pictures (small boxes) the radii are 4.42 / 4.88 / 5.54 / 6.07 / 6.50 mm (P1 vendored copy 4.35 / 4.80 / 5.45 / 5.98 / 6.40), the same ratios at a different scale.
- Notes: real size x 0.215 on booklet pages ($2 27.1 x 13.5 mm, $5 28.6 x 14.2, $10 30.3 x 14.8); real size x 0.118 in colour-by-code pictures ($2 14.9 x 7.4, $5 15.7 x 7.8, $10 16.6 x 8.1). Coins and notes are NOT drawn at the same scale as each other (a real $2 note is five times as wide as a $1 coin; on the page it is only about 1.4 times as wide), so the pages say "Pictures are not actual size."
- Differences between notes are small because the real notes differ by only 5 to 6 percent per step; the order $2 < $5 < $10 is correct in both width and height.

## Legibility constraints (checked on the rendered pages)

- The word "cents" (P1 and P2) and "dollar" (P2) is set at 2.8 mm type (P2 2.9 mm), cap height about 2.0 mm, which is above the 1.9 mm minimum. The word has to fit inside the 5c coin: its width is about 7 mm and the 5c coin is 13.4 mm across; the numeral and the word both fit with a margin (verified by viewing).
- Because the 5c coin is the smallest, the whole set was kept at 0.80 of real size (not smaller). The largest coin ($1, 19.7 mm; 50c 18.4 mm in P1) fits every layout (P1 S2-10, S2-11; P2 S2-01, S2-04).
- Colour-by-code coins show the cent sign instead of the word (the boxes are small); the numeral is 3.9 pt and the sign 2.9 pt.
- All lines are solid, black, at least 0.3 mm wide (0.85 pt); the dashed inner ring was removed from every coin.
