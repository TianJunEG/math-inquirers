Count by size: squares in a grid

How many squares of all sizes are in this 2 by 3 grid?

Step 1. Size 1 by 1: 3 in each of 2 rows = 6.

Step 2. Size 2 by 2: it can start in the left column or the next one = 2.

Step 3. Size 3 by 3: the grid is only 2 rows tall, so none.

6 + 2 = 8 squares. Counting by size means nothing is missed.

Try the next one on your whiteboard: how many squares in a 2 by 4 grid? (answer: 8 + 3 = 11)

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q4). Ask first: "How many squares?" Most children say 6. Click: the red square, then the teal square appear with step 2. Think-aloud: "I count by size, smallest first. 1 by 1: 6. Then 2 by 2: I slide the big square along: left or right, 2. 3 by 3 will not fit, so I stop." 6 + 2 = 8. The check slide for the next grid (2 by 4): size 1: 8; size 2: 3 positions; size 3: none; total 11.
