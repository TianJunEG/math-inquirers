3-digit numbers, all digits different, digits add up to 4.

a The smallest such number?

103

b The greatest such number?

310

c Between 7000 and 8000, my other three digits are all 2.

7222

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Whiteboards. a) and b): the only three different digits that add to 4 are 0, 1 and 3 (0 + 1 + 2 is only 3, and 0 + 1 + 3 = 4). Smallest: 103. Greatest: 310. Ask: "How do you know there are no other digits?" c) 7222. This prepares Q5b on the worksheet, where FOUR different digits add up to 6.
