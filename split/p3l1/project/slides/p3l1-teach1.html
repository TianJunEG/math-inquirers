Greatest and smallest: start at the left

The thousands place is worth the most, so decide it first.

Step 1. Greatest: biggest digit first, then the next biggest: 8 4 1 0

Step 2. Smallest: 0 cannot go first. Put the smallest digit that is not 0 first: 1

Step 3. Then the rest from smallest: 1 0 4 8

Greatest 8410 Smallest 1048 (not 0148: that is only 148)

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Teach. Children lay out 4, 0, 8, 1 on their mats. Think-aloud: "Greatest number from 4, 0, 8, 1. The thousands place is worth the most, so the biggest digit goes there: 8. Then 4, then 1, then 0: 8410. Smallest: I want the smallest digit first, but 0 cannot go first or it is not a 4-digit number. So 1 goes first, then 0, then 4, then 8: 1048." Ask: "Is 0148 a 4-digit number?" (No, it is 148.)
