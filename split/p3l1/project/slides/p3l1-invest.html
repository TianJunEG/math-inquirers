Investigation: What if one card changes?

The cards 1, 2, 3, 4 make 24 four-digit numbers: 6 start with each card. Now change the 4 card to a 0, so the cards are 0, 1, 2, 3.

1. Make a list in order of the numbers that start with 1. How many are there?

2. How many start with 2? With 3? With 0?

3. How many 4-digit numbers can you make altogether now? What stayed the same? What changed? Why?

Easy first step: with the cards 0, 1, 2, 3, write only the numbers that start with 1. Use the cards to help you.

DEBRIEF in talk time, minutes 72 to 75: ask for volunteers to share one thing they noticed (a pass is fine). Then show the model answer and ask "What stayed the same? What changed? Why?" Model answer and what to look for: Starting with 1: 1023, 1032, 1203, 1230, 1302, 1320 (6 numbers). 6 start with 2 and 6 start with 3. None start with 0 (0123 is only a 3-digit number). Altogether 18, not 24. Same: each of the cards 1, 2, 3 still makes 6 numbers. Changed: 0 cannot go first, so 6 numbers are lost (24 − 6 = 18). Look for: a list in order, a count by first digit, and the reason that zero cannot lead. Extension: how many are even? (10 with the cards 0, 1, 2, 3; 12 with the cards 1, 2, 3, 4.)
