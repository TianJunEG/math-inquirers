Challenge: walk-through

Q1: greatest, then smallest

Greatest: Th = 9. Three different digits, not 9, that add to 9.

Biggest hundreds digit: 8. Then 1 + 0. So 9810.

Smallest: the smallest sum of 3 different digits is 0 + 1 + 2 = 3.

So Th = 3, then 0, 1, 2 in order: 3012.

Q2: make a list in order

Start with 1: 1234, 1243, 1324, 1342, 1423, 1432. That is 6.

7th 2134, 8th 2143

9th 2314, 10th 2341

Answer: 2341. A list in order lets us count without missing any.
