Key idea: start at the biggest place

Decide the thousands digit first. To find every number, fix the first digit and list the rest in order.

Odd or even? Choose the ones digit first.

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Putting 0 first for the smallest number (0357 is really 357, a 3-digit number). (2) For the greatest odd number, making the greatest number first and then trying to fix it, instead of choosing the ones digit first. (3) Listing numbers in a random order, so some are missed or written twice (especially with the two 5s in Q2).
