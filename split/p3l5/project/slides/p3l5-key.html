Key idea: read the leftover

The remainder is always smaller than the number we divide by. Start number = groups × size + leftover.

Then ask: does the leftover need one more group, or is it left out?

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Leaving a remainder that is as big as, or bigger than, the number we divide by (60 ÷ 7 = 7 r 11). (2) Giving the division answer when the story needs one more group (minibuses, boxes for ALL the eggs), or adding one when only full groups count (books she can buy). (3) Stopping at the first number that fits one clue in a riddle, without testing the other clue or finding ALL the numbers.
