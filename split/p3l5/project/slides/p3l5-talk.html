Why can the remainder never be as big as the number we divide by?

Sentence starters:

“I noticed that …” “I tested it by …” “I know because …”

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Minutes 70 to 80. Pairs talk for 2 minutes, then share. Second question if time: "75 ÷ 9 = 8 r 3. Why was the minibus answer 9, not 8?" Answer: If the leftover were as big as the group size, we could make one more group, so the remainder is always smaller. The 3 pupils left over still need a seat, so we need one more minibus. Praise the reasons, not only the answers.
