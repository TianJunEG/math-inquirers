Investigation: Three counting patterns

A puzzle with more than one good answer. Share one way you tried it, or pass.

Pattern A: 1, 4, 7, 10 ... (add 3 each time). Pattern B: 2, 5, 8, 11 ... Pattern C: 3, 6, 9, 12 ...

(a) Write each pattern up to 30.

(b) Pick any number from 1 to 30. Which pattern is it in? Can a number be in two patterns? Can a number be in none?

(c) Why does this happen?

Easy first step: write pattern A, 1, 4, 7, 10 ..., up to 30.

Math Inquirers Level 2 Holiday Program • Notice it. Test it. Explain why.

Minutes 77 to 80 (3 minutes, after talk time). Investigation debrief. The Investigation is printed on the last core page of the workbook; children may have started it any time after question 3 (it is open to everyone), or it is take-home. Say to the whole group: "Who would like to share one way they tried the Investigation? Passing is fine." Ask for volunteers only; never name a child; no public tallies, scores or rankings. Several answers are right: praise the method (a list in order, a table, a drawing), not the speed. If nobody has started it, show the first step on the slide and let pairs try for one minute, then set it as take-home. Model answer and what to look for: (a) A: 1, 4, 7, 10, 13, 16, 19, 22, 25, 28. B: 2, 5, 8, 11, 14, 17, 20, 23, 26, 29. C: 3, 6, 9, 12, 15, 18, 21, 24, 27, 30. (b) Every number is in exactly ONE pattern (brute-forced for 1 to 99). (c) Counting in 3s, a number is either on the 3s (pattern C), 1 more than a number on the 3s (A), or 2 more (B); there is no other choice. Extension (not printed): if each pattern added 4 you would need 4 patterns, starting at 1, 2, 3 and 4. Look for: a complete listing, the claim “exactly one” tested on more than one number, and a reason that uses the 3 times table.
