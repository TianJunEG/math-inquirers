Count the groups

Beads: 1 blue, 3 green, 1 blue, 3 green … Ben uses 5 blue beads. The string ends with green beads. How many green beads? How many beads altogether?

Step 1. 1 blue and 3 green make one group of 4 beads.

Step 2. 5 blue beads, so there are 5 groups.

Green: 5 × 3 = 15. Altogether: 5 × 4 = 20 beads.

Math Inquirers Level 2 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 1 (Q3 counts beads in groups). Click through. Think-aloud: "Every group has exactly 1 blue bead, so counting blue beads counts the groups. 5 groups. Each group has 3 green: 3, 6, 9, 12, 15. Each group has 4 beads: 4, 8, 12, 16, 20." Ask: "Why did it matter that the string ends with green beads?" (So the last group is complete; if it stopped right after a blue bead, the last group would have no green.)
