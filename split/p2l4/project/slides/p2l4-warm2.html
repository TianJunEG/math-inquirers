Minutes 5 to 10. Read each one aloud, take answers, then click to show. Answers: 16, 35, 15, 40, 14. Ask for the rule each time: add 4; take away 5; add 3; the 10th number in the 4 times table is 4 × 10; add 3. For 5 ask: "Is this the 3 times table?" (No: it starts at 2. Each number is 1 less than a 3 times table number.)
