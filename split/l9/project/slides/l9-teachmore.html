Longer than, shorter than

A red ribbon is 7 cubes. Blue is 2 cubes longer than red. Green is 3 cubes shorter than red.

All three end to end: 7 + 9 + 4 = 20 cubes.

Read "than red": start from red's bar each time.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q5). Click to build each bar; before each click ask "Longer or shorter than red? By how much?" Think-aloud: "Blue is 2 longer than red, so I draw red's 7 and 2 more: 9. Green is 3 shorter than red, so I draw red's 7 and cross off 3: 4. End to end: 7 + 9 = 16, and 4 more is 20." Common mistake: adding 7 + 2 + 3 for the total, using the differences instead of the lengths.
