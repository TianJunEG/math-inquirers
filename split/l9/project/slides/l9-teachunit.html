Bigger unit, smaller number

1 clip is as long as 3 erasers. We measure one stick with both.

Same stick! Each clip covers 3 erasers, so we need fewer clips.

Your turn: A path is 5 of Tom's steps or 7 of Sue's steps. Who takes bigger steps?

Tom

Math Inquirers Level 1 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q3 and Q4). Use real clips and erasers if you have them (or draw). Click 1: the clips. Click 2: the erasers. Ask: "Is the stick longer when we use erasers?" (No, it is the same stick.) Click 3. Think-aloud: "A bigger unit covers more of the stick each time, so I need fewer of them. A smaller unit gives a bigger number." Your turn: whiteboards, then click. "Tom needs fewer steps for the same path, so each of his steps is bigger." Do not tell them the Q3 answer: it is the same idea with hand spans.
