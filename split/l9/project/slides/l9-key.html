Key idea: measure fairly

Use equal units with no gaps and no overlaps. Line up the ends.

On a ruler, count the cm spaces from one end to the other.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Counting a ribbon's squares carelessly or counting a square twice: touch each one. (2) Answering "how much longer" with the length instead of the difference. (3) "End to end" means add the two lengths. (4) Leaving gaps between cubes in Q2. (5) On a ruler, reading the end mark when the object does not start at 0.
