Change the unit: both ways

1 clip is as long as 3 erasers.

Clips to erasers: a rope is 4 clips long.

Step A. Each clip is 3 erasers: 3, 6, 9, 12. The rope is 12 erasers long.

Erasers to clips: a book is 6 erasers long.

Step B. Put the erasers in groups of 3: 3, 6. That is 2 groups, so the book is 2 clips long.

To a smaller unit: the number gets bigger. To a bigger unit: the number gets smaller.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q4 goes both ways). Left side, click 1: draw 3 erasers under each clip. Click 2: count in 3s along the erasers: 3, 6, 9, 12. Think-aloud: "4 clips, and every clip is 3 erasers, so 3 and 3 and 3 and 3: 12 erasers." Right side, click 3: ring the erasers in 3s. Click 4: "6 erasers make 2 groups of 3, so 2 clips. I check: 3 + 3 = 6." Click 5: the summary. Ask: "Changing to erasers, did the number get bigger or smaller? Why?" The worksheet uses 1 clip = 2 erasers: the same method, groups of 2.
