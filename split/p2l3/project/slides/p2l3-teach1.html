Arrays: rows of equal groups

Step 1. Count the rows: 3. Count how many in each row: 4.

Step 2. 3 rows of 4: 4, 8, 12. So 3 × 4 = 12.

Step 3. Turn it round: 4 rows of 3. 4 × 3 = 12.

Step 4. Share 12 into 3 rows: 12 ÷ 3 = 4. Groups of 4: 12 ÷ 4 = 3.

Math Inquirers P2 Holiday Program • Notice it. Test it. Explain why.

Teach. Build 3 rows of 4 counters while the children copy. Click to reveal each step. Think-aloud: "3 rows of 4 dots. I count the rows: 3. I count how many in each row: 4. 4, 8, 12. So 3 × 4 = 12. If I turn my head, it is 4 rows of 3, so 4 × 3 = 12 too. Sharing 12 into 3 rows gives 4 in each row: 12 ÷ 3 = 4. Putting 12 in groups of 4 gives 3 groups: 12 ÷ 4 = 3." Ask: "One array, how many number sentences?" (four: two × and two ÷). Say: "An array is a DRAW IT tool: it shows the groups so we can see the times table."
