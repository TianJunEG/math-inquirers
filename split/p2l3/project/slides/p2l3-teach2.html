Math Inquirers P2 Holiday Program • Notice it. Test it. Explain why.

Teach. Click: the first note, then each table row, then the swap note and the answer (or reveal the rows as the children call them out). Think-aloud: "6 vehicles, bicycles and cars, 16 wheels. I start with all bicycles: 6 bicycles is 12 wheels. Too few. I swap one bicycle for a car: a car has 2 more wheels than a bicycle, so that adds 2 wheels, 14. Swap again: 16. So 4 bicycles and 2 cars. Check BOTH clues: 8 + 8 = 16 wheels, 4 + 2 = 6 vehicles." Say: "This is MAKE A TABLE. It is also guess and check, but tidy: every row is a guess, and the table shows us the pattern so we know which way to go."
