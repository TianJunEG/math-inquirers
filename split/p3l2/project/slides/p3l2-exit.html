Minutes 80 to 86. Answer: 563 + 126 = 689 (A = 6). Ones 3 + 6 = 9; tens A + 2 = 8, so A = 6; hundreds 5 + 1 = 6. Extension: find three sums of two 3-digit numbers with a 3-digit answer that use the digits 1 to 9 once each; add the digits of each answer (always 18).
