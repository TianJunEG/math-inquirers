AB + BA = CAC: two 2-digit numbers make less than 200, so C = 1. Ones: B + A ends in 1, so B + A = 11, carry 1. Tens: A + B + 1 = 12, and the middle digit of the answer is A, so A = 2 and B = 9: 29 + 92 = 121. For Q6 itself (AB + AB + AB = CAB) the idea is the same: start with what the ones digit must be.
