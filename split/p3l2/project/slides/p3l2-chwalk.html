Challenge: walk-through

Q1: guess, check, improve

Thousands digits next to each other, like 5 and 4.

Bigger number: the rest as SMALL as possible: 5123.

Smaller number: the rest as BIG as possible: 4876.

5123 − 4876 = 247. Try 4 and 3: 4125 − 3876 = 249. So 5 and 4 win.

Q2: one column at a time

Tens: ■ + ● + carry ends in ■, so ● + carry = 10. ● = 9, carry 1.

Hundreds: ★ + ★ + 1 = ● = 9, so ★ = 4.

Ones: ● + ■ = 9 + ■ ends in ★ = 4, so ■ = 5.
