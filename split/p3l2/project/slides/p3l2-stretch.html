Stretch

1. ◆● + ● = ●◆. Different shapes are different digits. Find ◆ and ●.

2. Use the 9999 trick: 10 000 − 3746 = ?

3. ▲▲ + ■■ = ●■●. Different shapes are different digits. Find them.

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Answers: 1) ◆ = 8, ● = 9: 89 + 9 = 98 (the answer is bigger than the first number by only ●, so the tens go up by 1: ● = ◆ + 1; ones: ● + ● = 10 + ◆; try ◆ = 8). 2) 6254 (9999 − 3746 = 6253, then 1 more). 3) ▲ = 9, ■ = 2, ● = 1: 99 + 22 = 121 (● must be 1; ones ▲ + ■ ends in 1, so they make 11; tens 11 + 1 = 12, so ■ = 2 and ▲ = 9).
