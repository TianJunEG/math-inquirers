Letter puzzles: what must each letter be?

Each letter is a digit. Different letters are different digits.

Step 1. Two 2-digit numbers make less than 200, so C = 1.

Step 2. Ones: B + A ends in 1, so B + A = 11. Carry 1.

Step 3. Tens: A + B + 1 = 12. The middle digit of the answer is A, so A = 2. Then B = 9.

29 + 92 = 121 ✓ A = 2, B = 9, C = 1
