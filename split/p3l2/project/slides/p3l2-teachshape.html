Shape puzzles: what must each shape be?

Each shape is a digit. Different shapes are different digits.

Step 1. Two 2-digit numbers make less than 200, so ▲ = 1.

Step 2. Ones: ■ + ◆ ends in 1, so ■ + ◆ = 11. Carry 1.

Step 3. Tens: ◆ + ■ + 1 = 12. The middle digit is ◆, so ◆ = 2. Then ■ = 9.

29 + 92 = 121 ✓ ◆ = 2, ■ = 9, ▲ = 1
