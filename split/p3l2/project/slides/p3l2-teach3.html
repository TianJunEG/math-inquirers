The bigger number gets the SMALL ones digit, the smaller number gets the BIG one.

Smallest difference: 31 − 24 = 7

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Teach the heuristic GUESS AND CHECK, then IMPROVE. Click for each row and note. Think-aloud: "First guess 43 − 21 = 22. Can I do better? The tens make the biggest difference, so the tens digits should be next to each other, like 3 and 2." Row 2: 42 − 31 = 11, better. Row 3: try the tens 3 and 2 with the ones swapped round. "Now the bigger number, 3_, should have the smallest ones digit left, 1, and the smaller number, 2_, the biggest, 4: 31 − 24 = 7." Check other pairs quickly: 41 − 32 = 9, 21 − 14 is not allowed (1 twice). So 7 is the smallest.
