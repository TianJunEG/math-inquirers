Bonds of 10: list them in order

Start with 0. Each time, the first number goes up by 1.

0 + 10

1 + 9

2 + 8

3 + 7

4 + 6

5 + 5

The first number goes up by 1, the second goes down by 1. When we reach 5 + 5, the next ones are the same pairs turned round (6 + 4, 7 + 3 …). That is how we know we have them all.

Math Inquirers Level 1 Holiday Program • Notice it. Test it. Explain why.

Teach. Click to add each bond while children say it with you; show each on a ten-frame (red and yellow counters). Think-aloud: "Let me list them in order: 0 + 10, 1 + 9, 2 + 8. What do you notice? The first number goes up by 1 and the second goes down by 1. That is how I know I have them all." Then the summary: 11 bonds from 0 + 10 to 10 + 0, or 6 different pairs if 3 + 7 and 7 + 3 count as the same.
