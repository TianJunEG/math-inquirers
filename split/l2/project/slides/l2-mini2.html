Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Worked example 2. Ask children to explain each step in their own words. List the pairs in order: 0+10, 1+9, 2+8 … Notice one goes up by 1 as the other goes down by 1. Link to 20: 6+4=10, so 16+4=20. Answer: 3. Check: 6 + 2 = 8 and 5 + 3 = 8. Common mistake: writing 8 because the answer “comes next”.
