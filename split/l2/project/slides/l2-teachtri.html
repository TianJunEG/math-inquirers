Magic triangles: think about the corners

Put 1, 2, 3, 4, 5 and 6 in the circles so each side adds up to 12.

Step 1. Each corner is on TWO sides. Big sides need big corners: try 4, 5 and 6.

Step 2. Side 4 + ? + 5 = 12, so ? = 3. Side 5 + ? + 6 = 12, so ? = 1.

Step 3. Side 6 + ? + 4 = 12, so ? = 2. Every number used once ✓

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q5). Here the target is 12, so the BIG numbers go in the corners. On the worksheet the target is 9: ask "Small sides... so which numbers should go in the corners?" but do not tell them. Click order: step 1, corners appear, step 2, step 3, the finished triangle.
