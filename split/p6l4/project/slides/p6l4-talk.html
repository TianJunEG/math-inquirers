Minutes 78 to 83. One question only. Pairs talk for 90 seconds, then volunteers share. Both get n = 9. Backwards is quicker by hand and works for big numbers (4n + 7 = 4007 would take Ravi 1000 tries). Trying every n is easy to code and also works when there is no easy backwards step, like n × n + n = 90 (n = 9). But a search must stop: if there is no whole-number answer, it would run forever. Praise answers that say WHEN each is better.
