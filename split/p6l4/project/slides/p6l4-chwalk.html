Challenge: walk-through

Q1: make a table

IN 1 → OUT −1. IN 2 → OUT 2 ✓ IN 3 → OUT 5.

OUT grows by 3 each time, IN by 1, so they meet only once.

With n: 3n − 4 = n. Take n from both sides: 2n − 4 = 0, so n = 2.

Q2: go backwards twice

Second machine backwards: 63 − 1 = 62, 62 ÷ 2 = 31.

First machine backwards: 31 − 1 = 30, 30 ÷ 2 = 15.

Check forwards: 15 → 31 → 63 ✓

Math Inquirers P6 • Notice it. Test it. Explain why.

Use after pairs have tried. Q1: the table is the computer-style search done by hand; the algebra line is for strong pupils only. Q2: the middle box is 31. Extra for fast pairs: the two joined machines are the same as one machine "× 4, then + 3" (5 → 23: 4 × 5 + 3 = 23; 15 → 63: 4 × 15 + 3 = 63). Why? (2n + 1) × 2 + 1 = 4n + 3.
