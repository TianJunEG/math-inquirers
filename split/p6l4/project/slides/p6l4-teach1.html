+4 each time

When IN goes up by 1, OUT goes up by 4.

Step 1. OUT goes up by 4 each time, so the rule has × 4 in it: 4n.

Step 2. Test: IN 1 gives 4 × 1 = 4. But OUT is 7, so add 3.

Step 3. Rule: OUT = 4n + 3. Check IN 4: 4 × 4 + 3 = 19 ✓

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach. Click: the "+4 each time" note, then the steps. Think-aloud: "Every time n goes up by 1, OUT goes up by 4. That is what times 4 does: 4, 8, 12, 16. The 4-times table is 3 less than my OUT every time, so I add 3." Link to Lesson 1: this is the nth term idea. Always check the rule on a pair you did not use.
