1. Which IN numbers were the most useful for cracking a rule? Why?

2. How did you write your partner’s rule with n?

3. My machine is × 3, then + 2. It says 20. How can you find the IN without trying lots of numbers?

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 15 to 25. Let pairs keep working, then gather them. Answers: 1) Numbers in a row (1, 2, 3) show the × part: OUT goes up by the × number each time. IN 0 shows the + part straight away (0 × 3 + 2 = 2). 2) Times part first, then the add part: 3n + 2 means n × 3, then + 2. 3) Run it backwards: undo + 2 first (20 − 2 = 18), then undo × 3 (18 ÷ 3 = 6). Check: 6 × 3 + 2 = 20.
