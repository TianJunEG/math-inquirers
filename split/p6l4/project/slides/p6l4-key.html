Key idea: a rule is a machine

A rule with a letter is a machine: OUT = 3n + 2 means × 3, then + 2. To find IN from OUT, run it backwards: undo the last step first.

Check every answer by running the machine forwards.

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 33.5 to 34.5. Say the key idea together. Common mistakes to watch for during the worksheet: (1) Finding a rule from the first pair only (1 → 6 "add 5") without checking the others. (2) Undoing the steps in the wrong order, or doing the same step again instead of the opposite. (3) Reading 4n + 1 as "add 1 then times 4", or forgetting that brackets are done first.
