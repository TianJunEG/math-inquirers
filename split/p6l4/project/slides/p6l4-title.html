Algebra Machines

Expressions and equations • Code: input, rule, output

TODAY WE WILL

Find a machine’s rule and write it with a letter, run machines backwards to solve equations, and build a machine in code.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Find the rule of a function machine from a table and write it with a letter (OUT = 3n + 2); see that the order of steps matters and use brackets; solve simple equations by running the machine backwards (undo the last step first) and check forwards; build an input-rule-output program and use a search loop to test an answer. Materials: laptop or desktop with Scratch 3 (scratch.mit.edu), mini whiteboard and marker, workbook, pencil. Tutor: this deck, Scratch open for screen share. Online set-up: for the explore, children work in pairs in breakout rooms; one partner shares their screen with the machine running and types in the numbers the other partner calls out. Page 1 of the worksheet is paper only. Time plan: warm-up 0 to 10, explore at the computer 10 to 25, teaching 25 to 35 (click to reveal each step and answer), brain break 35 to 40, worksheet 40 to 70 with short teaching before each page and a check-together slide after it, talk time 70 to 80, exit ticket 80 to 90.
