Algebra Machines

Expressions and equations • Code: input, rule, output

TODAY WE WILL

Find a machine’s rule and write it with a letter, run machines backwards to solve equations, and build a machine in code.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Find the rule of a function machine from a table and write it with a letter (OUT = 3n + 2); see that the order of steps matters and use brackets; solve simple equations by running the machine backwards (undo the last step first) and check forwards; build an input-rule-output program and use a search loop to test an answer. Materials: laptop or desktop with Scratch 3 (scratch.mit.edu), mini whiteboard and marker, workbook, pencil. Tutor: this deck, Scratch open for screen share. Online set-up: for the explore, children work in pairs in breakout rooms; one partner shares their screen with the machine running and types in the numbers the other partner calls out. Page 1 of the worksheet is paper only. Block colours on our slides are simplified; in Scratch, find blocks by the category name on the left, not by colour. Time plan (the exact minutes of this lesson, with a standing flex buffer): opening 0 to 2, sneak-peek puzzles 2 to 6, warm-up 6 to 12.5, explore at the computer 12.5 to 26.5, mini-lesson 26.5 to 34.5 (click to reveal each step and answer), brain break 34.5 to 40, worksheet 40 to 74.5 with short teaching before each page and a check-together slide after it, flex 74.5 to 78 (unscripted: use it for Think harder or catch-up; it is lost first), talk time 78 to 83, exit slip 83 to 86, looking back 86 to 88, close and stamp 88 to 90.
