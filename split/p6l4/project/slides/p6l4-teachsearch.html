Let the computer search

Solve 6n + 5 = 71 by trying n = 0, 1, 2, 3 … until it works.

Step 1. n = 0 gives 5, n = 1 gives 11, n = 2 gives 17 … not 71 yet, keep going.

Step 2. It stops when n = 11 (66 + 5 = 71) and says 11.

Step 3. By hand, backwards: 71 − 5 = 66, 66 ÷ 6 = 11 ✓

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q6 plans a search). "repeat until" is in Control; the = block is in Operators. The computer is not clever, it is fast: it tries every n. Our backwards method is clever: it goes straight there. Both give 11. Ask: "What happens if the equation has no whole-number answer, like 6n + 5 = 70?" (it never stops: press the red stop sign). Python version: n = 0 | while n * 6 + 5 != 71: n = n + 1 | print(n) (prints 11).
