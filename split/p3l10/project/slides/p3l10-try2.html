Your turn: a small logic grid

Ali, Mei and Ben each choose a different colour: red, blue, green.

a Mei does not choose red or blue. Ali does not choose red.

Mei: green

b So what does Ali choose?

Ali: blue

c And Ben?

Ben: red

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Whiteboards: draw a 3 by 3 grid. Mei has 2 crosses, so green is the only one left: tick, then cross green for Ali and Ben. Ali is not red, and green is gone, so blue. Ben gets red. Check: Mei green (not red or blue ✓), Ali blue (not red ✓).
