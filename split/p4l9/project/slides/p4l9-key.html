Key idea: scale first, then the changes

Read the scale before you read a point. The steeper the line, the bigger the change.

Totals help you find missing values. Check where the scale starts before you compare two graphs.

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Reading the scale as 1 for each line when each line is worth 10 (or 5), so 75 is read as 7 and a half. (2) Looking only for the biggest increase and missing a bigger decrease, or comparing the heights of points instead of the change between them. (3) Comparing two graphs by how steep the lines look without checking where each scale starts and what each line is worth.
