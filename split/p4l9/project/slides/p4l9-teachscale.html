Check the scale!

Same numbers: 52, 54, 56, 58. Both went up by only 6 cars! Graph 2 starts at 50 and each line is 2.

Before you compare graphs: where does the scale start? What is each line worth?

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q5, the two shops). Ask first: "Which car park got much busier?" Most children say Graph 2. Then let them read the numbers from both graphs: they are the same! Click. Think-aloud: "Graph 2 does not start at 0. It starts at 50, and each line is only 2, so a small change looks huge. Graph 1 starts at 0, so the same change looks tiny. Neither graph is wrong, but Graph 2 can trick you." Someone who wants the change to look big, like an advert, would draw Graph 2.
