Minutes 80 to 84.5. Pair talk is 1 minute (no breakout rooms: children tell the grown-up beside them, or write one sentence), then share. Answer: the scales are different. If a scale starts at a big number, or each line is worth very little, a small change looks huge. Not asked in class (moved to the Weekly Dose of Thinking Math): "How would you draw a fair graph if you wanted to compare two shops?" (use the same scale for both graphs, starting at 0). Praise the reasons, not only the answers. TALK TIME RULES: ask for volunteers first; a child may always pass; never call on a child by name to answer; no public tallies, scores or rankings; praise the reason, not the child. If a question uses a mistaken idea (a character who gets it wrong), present it as the character's idea and ask "What would you say to them?" so no child owns the mistake. TOOL MINUTE: Talk time is one minute longer than before (the common look-back is shorter). Spend it on the question on the slide: where did you use today's tool, and what did it help you see? Listen for the tool named, not for the answer; a child may pass.
