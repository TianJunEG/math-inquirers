Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Minutes 80 to 85. Pairs talk for 2 minutes, then share. Answer: the scales are different. If a scale starts at a big number, or each line is worth very little, a small change looks huge. To compare fairly, use the same scale for both graphs, starting at 0. Second question if time: "Why did we list the changes instead of just looking at the highest point?" (the highest point shows the biggest number, not the biggest change). Praise the reasons, not only the answers. TALK TIME RULES: ask for volunteers first; a child may always pass; never call on a child by name to answer; no public tallies, scores or rankings; praise the reason, not the child. If a question uses a mistaken idea (a character who gets it wrong), present it as the character's idea and ask "What would you say to them?" so no child owns the mistake.
