Ben says, “A triangle with longer sides always has a bigger area.” Is he right?

Sentence starters:

“The base is … and the height is …” “They have the same … so …”

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Minutes 76 to 82. Pairs talk for 2 minutes, then share. Answer: No. Two triangles with the same base and the same height have the same area, even if one leans over and has much longer sides. The area depends on the base and the height, not on the slanting sides. A long, thin triangle can have a smaller area than a short, wide one. Ask: "Can you draw a triangle with one very long side and a tiny area?" (Yes: a long base with a tiny height.) Praise reasons, not only answers.
