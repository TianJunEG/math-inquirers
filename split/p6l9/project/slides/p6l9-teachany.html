Make it work for ANY list

We add an 8 to the goals list: 3, 0, 4, 1, 2, 8. True mean: 18 ÷ 6 = 3.

This program says 2. Why?

Step 1. repeat 5 stops after item 5, so the 8 is never added. Total is still 10.

Step 2. And it divides by 5, not 6.

Step 3. Fix: use (length of data) in BOTH places. Now it says 18 ÷ 6 = 3 ✓

Math Inquirers Level 6 • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q5 asks which blocks must change). Think-aloud: "A number typed into the code is fixed. When the list grows, the program does not know. length of data is always the right count, so the loop visits every item and we divide by the right number." Try it live: add 8 to the list and run both versions.
