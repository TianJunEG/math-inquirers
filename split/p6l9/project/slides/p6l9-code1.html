Math Inquirers Level 6 • Notice it. Test it. Explain why.

Build it live in Scratch while children copy (Variables: make total and i; make a list called data). Then trace it on the slide: click to add each row. Think-aloud: "i starts at 1, so item 1 of data is 3: total becomes 3. Change i by 1. Item 2 is 0: total stays 3. Item 3 is 4: total 7. Item 4 is 1: total 8. Item 5 is 2: total 10. The loop ran length of data = 5 times. 10 ÷ 5 = 2." Why "length of data" and not 5? Then the program still works when the list grows (teaching slide before page 2). Python version (optional, for children who know Python): data = [3, 0, 4, 1, 2] # goals in 5 matches total = 0 for value in data: total = total + value mean = total / len(data) print("Total:", total) print("Mean:", mean) above = 0 for value in data: if value > mean: above = above + 1 print("Above the mean:", above) It prints: Total: 10, Mean: 2.0 (Python writes 2 as 2.0 after a division), Above the mean: 2.
