What changes the mean?

Data: 2, 4, 6. Mean 4. Predict first: up, down or the same? Then the new mean.

a Add a new value: 4

same: 4

b Add 1 to every value

up: 5

c Remove the 6

down: 3

d Change the 6 to 18

up: 8

Math Inquirers P6 Holiday Program • Notice it. Test it. Explain why.

Predict with thumbs (up, down, sideways) before each click. a) 16 ÷ 4 = 4: a value equal to the mean keeps it the same. b) 3, 5, 7: 15 ÷ 3 = 5; every value up by 1, so the mean goes up by 1. c) 2, 4: 6 ÷ 2 = 3; removing a value above the mean pulls it down. d) 2 + 4 + 18 = 24, 24 ÷ 3 = 8: the total went up by 12, shared by 3 values, so the mean went up by 4.
