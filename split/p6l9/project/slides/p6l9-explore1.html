Math Inquirers Level 6 • Notice it. Test it. Explain why.

Minutes 10 to 15. Everyone types the number of letters in their full name (no spaces) in the chat; copy the list onto the slide or a shared board. Each child estimates the mean, then works it out by hand (total ÷ how many), then opens the starter project (or builds the 5 blocks shown; full program on the code slide later) and types each value into the list called data with the + button under the list. Run it. Then the prediction: "Our tutor joins with a 30-letter name. Will the mean go up a little or a lot?" Add 30 to the list and run again. The picture uses example data (12, 9, 15, 11: mean 47 ÷ 4 = 11.75); your class data will differ. Online: children share their screen when their program runs. If Scratch is slow, pairs can share one screen. Watch for children who divide by the wrong count or who type a value twice.
