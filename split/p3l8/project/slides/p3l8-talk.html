Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Minutes 72 to 80. Pairs talk for 2 minutes, then share. Answer: No. The size of an angle is how far the arms open. Test: draw the same angle twice, once with long arms and once with short arms, and put the checker on both: it fits the same way. Or open two pencils the same amount, then slide one out. Follow-up: "How did you make sure you did not miss any angles?" (Count small ones first; visit every meeting point.) INVESTIGATION DEBRIEF (first 3 minutes, 72 to 75): volunteers share what they noticed, then use the model answer in the notes of the Investigation slide. Not finished? It can be shared at the start of next lesson. Then the talk question below. TALK TIME RULES: ask for volunteers first; a pass is always fine and so is sharing with a partner.
