Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Line up the points: today's main idea. Click to fill each row of the place-value chart; children say the digits first. Point out the 0s in grey places: "4.37 has no thousandths. I can write a 0 there: 4.370. It is the same number." Then the side notes. Think-aloud: "All have 4 ones. Tenths: 3, 3, 0, 3. The 0 tenths is smallest: 4.073. Now 4.300, 4.307, 4.370. Hundredths: 0, 0, 7. So 4.37 is the biggest. 4.300 and 4.307: thousandths 0 and 7, so 4.3 comes first." Common mistake: "4.307 has more digits so it is bigger."
