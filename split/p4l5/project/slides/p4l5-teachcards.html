Closest to a target: check both sides

Use 1, 4, 8 and the point once each. Which number is closest to 3?

Step 1. There is no 3 card. Just below 3: start with 1, make the rest big: 1.84

Step 2. Just above 3: start with 4, make the rest small: 4.18

Step 3. How far? 3 − 1.84 = 1.16. 4.18 − 3 = 1.18.

1.84 is closest (by just 0.02!)

Math Inquirers Level 4 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q4 uses digit cards 3, 6, 9). Ask first: "Which do you think is closer to 3?" Most children pick one side without checking. Click through. Think-aloud: "Below 3 I want the biggest number that starts with a smaller digit: 1, then the biggest digits: 1.84. Above 3 I want the smallest number starting with a bigger digit: 4.18. Now I measure both distances." The lesson: always check both sides of the target.
