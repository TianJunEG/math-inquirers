Ben says 3.405 is bigger than 3.45 because 405 is bigger than 45. Who agrees? How can we check?

Sentence starters:

“I noticed that …” “I tested it by …” “I know because …”

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Minutes 70 to 80. Pairs talk for 2 minutes, then share. Answer: Ben is wrong. Line up the points: 3.405 and 3.450. Same ones, same tenths; 0 hundredths is less than 5 hundredths, so 3.405 is smaller. A number line check: 3.405 is just past 3.40; 3.45 is halfway to 3.5. Second question if time: "Why does 3.45 = 3.450, but 3.45 is not the same as 3.045?" (a 0 at the end adds nothing; a 0 after the point moves the other digits to smaller places). Praise the reasons, not only the answers.
