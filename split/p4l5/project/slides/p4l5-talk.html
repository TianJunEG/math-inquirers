Minutes 79.5 to 84. Pair talk is 1 minute (no breakout rooms: children tell the grown-up beside them, or write one sentence), then share. Answer: Ben is wrong. Line up the points: 3.405 and 3.450. Same ones, same tenths; 0 hundredths is less than 5 hundredths, so 3.405 is smaller. A number line check: 3.405 is just past 3.40; 3.45 is halfway to 3.5. Not asked in class (moved to the Weekly Dose of Thinking Math): "Why does 3.45 = 3.450, but 3.45 is not the same as 3.045?" (a 0 at the end adds nothing; a 0 after the point moves the other digits to smaller places). Praise the reasons, not only the answers. TALK TIME RULES: ask for volunteers first; a child may always pass; never call on a child by name to answer; no public tallies, scores or rankings; praise the reason, not the child. If a question uses a mistaken idea (a character who gets it wrong), present it as the character's idea and ask "What would you say to them?" so no child owns the mistake. TOOL MINUTE: Talk time is one minute longer than before (the common look-back is shorter). Spend it on the question on the slide: where did you use today's tool, and what did it help you see? Listen for the tool named, not for the answer; a child may pass.
