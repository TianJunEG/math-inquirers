Explore: what to do

EXPLORE

  1. Take the digit cards 2, 5, 8 and the decimal point card.
  2. Make a decimal with all four cards. The point goes between two digits.
  3. Make as many different numbers as you can. Write each one down.
  4. Put them in order. Which one is closest to 5?

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Minutes 8 to 13. Pairs work with digit cards 2, 5, 8 and a decimal point card (online: paper cards on camera). Ask them to predict first: how many numbers? Let them record numbers in any order at first. Ask "Where can the point go?" (after the first digit or after the second digit; not at the start or the end, because then it is not between two digits). Early finishers: which number is closest to 50? (52.8, only 2.8 away; 58.2 is 8.2 away).
