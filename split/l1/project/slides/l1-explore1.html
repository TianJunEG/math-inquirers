Explore: what to do

EXPLORE

  1. Make a number strip from 0 to 50.
  2. Frog 1 starts on 0 and jumps in 4s. Mark each landing with a red cross.
  3. Frog 2 starts on 0 and jumps in 5s. Mark each landing with a blue circle.
  4. Write down the numbers that have BOTH a cross and a circle.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 10 to 15. Pairs work with the materials: Paper number strip 0 to 50 (or floor tape), counters, two crayons. Pairs hop a counter along the number strip: frog 1 in 4s, frog 2 in 5s. Mark where each lands. Which numbers do both frogs land on? Online: Slide number line the tutor can mark on; each child uses a paper strip and a pencil.
