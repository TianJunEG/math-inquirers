Count with the Frog

Number Patterns

TODAY WE WILL

Count in 2s, 3s and 5s, find the rule and spot numbers that two patterns share.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Objective: Skip count in 2s, 3s and 5s; find and state an add or take-away rule; notice numbers that both counting patterns share. Materials: Paper number strip 0 to 50 (or floor tape), counters, two crayons. Online: Slide number line the tutor can mark on; each child uses a paper strip and a pencil. Time plan: warm-up 0 to 10, explore 10 to 25, mini-lesson 25 to 35, brain break 35 to 40, worksheet 40 to 70, talk time 70 to 80, exit ticket 80 to 90.
