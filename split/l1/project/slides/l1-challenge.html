For any pair that chooses Go further. Use it as a pair choice, or with volunteers in talk time (never call a child by name). Ask for the reason every time. Q3 is open: there is no single right answer, so ask children to check each other's work. Answers: 1) 29. The gaps are 1, 2, 3, 4, 5, 6, 7, so the 7th is 22 and the 8th is 29. 2) 5, 17, 29 and 41. Each one is 12 more than the one before. 3) Open. Check by writing both lists and ringing the matches. Example: start 2 add 4 (2, 6, 10 …) and start 3 add 3 (3, 6, 9 …) share 6, 18, 30 and 42, with a gap of 12 each time.
