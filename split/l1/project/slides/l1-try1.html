No

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Children write on whiteboards and hold them up together. Click for each answer. a) Add 4: 13 + 4 = 17, 17 + 4 = 21. b) The numbers go down, so take away 3: 25 − 3 = 22. Anyone who writes 28 has added: ask "Are the numbers getting bigger or smaller?" c) Add 5: 19, 24, 29, 34. It jumps from 29 to 34, so 30 is not in the pattern.
