Key idea: find the rule

Find the jump between two neighbours. Check it on every pair. Going up: add. Going down: take away.

A rule lets us test any number: keep jumping and see if we land on it.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Counting the numbers in between instead of the hops: from 4 to 7 they count "5, 6" and say the jump is 2. Put a finger on 4 and say a number for every hop: 5, 6, 7 is 3 hops. (2) Writing "add 3" when the numbers go down (it is take away 3). (3) Restarting the count from 0 instead of adding to the last number. (4) Q4: missing 50, or listing numbers only one child says.
