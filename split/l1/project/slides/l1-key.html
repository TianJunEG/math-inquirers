33–35 MIN

Key idea: find the rule

The rule tells you how much the number changes each time.

Check it on every pair of neighbours. Numbers that go down use take away.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 33 to 35. Say the key idea together. Common mistakes to watch for during the worksheet: (1) Reading the gap squares instead of the jump size. (2) Writing "add 3" when the numbers go down (take away 3). (3) Restarting the count instead of adding to the last number.
