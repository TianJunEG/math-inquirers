Key idea: work backwards

To find a mystery number, undo each step. Start with the last step. Then check by going forwards.

Opposites: + and − undo each other.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Adding again instead of undoing (12 + 5). (2) Two steps: undoing in the wrong order. (3) Queue questions: counting a child twice, or adding numbers without drawing the queue.
