Worked example: a regular octagon

What turn draws a regular octagon? What is each inside angle?

Step 1. Going once round, the turtle turns 360° altogether.

Step 2. 8 equal turns: 360° ÷ 8 = 45° at each corner.

Step 3. Inside angle = 180° − 45° = 135°.

To come home facing the same way the turtle turns 360° altogether, so each turn is 360 ÷ 8 = 45°. The turn and the inside angle sit on one straight line, so the inside angle is 180 − 45 = 135°." Optional Python version (Python turtle module; it opens a drawing window), for children who already know Python: import turtle t = turtle.Turtle() n, k = 5, 2 # points, rounds turn = 360 * k / n for i in range(n): t.forward(150) t.right(turn) print(turn, n * turn) turtle.done() Run as it is, it draws the 5-point star and prints 144.0 720.0 (the turn, then the total turning). Change n and k: n, k = 8, 1 draws the octagon and prints 45.0 360.0.
