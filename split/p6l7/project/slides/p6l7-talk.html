Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 70 to 80. Pairs talk for 2 minutes, then share. Second question if time: Why do the turns add up to 360° for every shape the turtle draws going round once? Answer: Mei is right. For an equilateral triangle the inside angle is 60° but the turtle turns 120°; turning 60° three times only draws half a hexagon. The turtle starts facing one way and comes home facing the same way after going round once, so it has made exactly one full turn: 360°. A star goes round more than once, so its turns add up to 720°, 1080° and so on. Praise the reasons, not only the answers.
