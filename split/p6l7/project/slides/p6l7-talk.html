Second question (only if flex is left; otherwise the opener of the next lesson): Why do the turns add up to 360° for every shape the turtle draws going round once?” (Only if flex is left; otherwise it is the opener of the next lesson.) Answer: Mei is right. For an equilateral triangle the inside angle is 60° but the turtle turns 120°; turning 60° three times only draws half a hexagon. The turtle starts facing one way and comes home facing the same way after going round once, so it has made exactly one full turn: 360°. A star goes round more than once, so its turns add up to 720°, 1080° and so on. Praise the reasons, not only the answers.
