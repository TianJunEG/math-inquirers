EXPLORE, IN PAIRS

  1. Open Scratch and add the Pen extension. Build: pen down, repeat 4 [move 100, turn right 90].
  2. Change it to draw an equilateral triangle. Predict the turn first, then run it.
  3. Now a regular pentagon (5 sides) and a regular hexagon (6 sides). Predict, then test.
  4. Record sides, turn and “did it close?”. What do sides × turn always make?

Record in a table: sides, turn, did it close?

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 10 to 15 (pairs keep going until 25). One child drives Scratch, the other predicts the turn BEFORE each run; swap for each shape. Build the square program together first and run it. Then the challenge: change one number to get an equilateral triangle. Expect many pairs to type 60 (the inside angle): let them run it. It draws only half a hexagon. Ask: "How far did the turtle turn altogether? Did it come home?" Then pentagon (5 sides) and hexagon (6 sides). Finished early: a regular shape with 10 sides. Online: breakout rooms, the driver shares their screen. Tip: add "erase all" and "go to x: 0 y: 0" at the top so each run starts clean.
