Investigation: Find all the ways to pay

Ali pays exactly 50 cents using only 5-cent, 10-cent and 20-cent coins. He can use as many of each coin as he likes.

1. Find all the ways. Write each way in the table (how many of each coin).

2. Which way uses the FEWEST coins? Which uses the MOST?

3. How do you know you have found them all?

Easy first step: pay 50 cents with ten 5-cent coins. Then swap some of them for 10-cent coins. A table for your answers is on the Investigation page of the workbook.

Do not say who is on which one. Not finished at 72? Take it home and bring one thing to share at the start of next lesson (volunteers only). DEBRIEF in talk time, minutes 72 to 75: ask for volunteers to share one thing they noticed (a pass is fine). Then show the model answer and ask "What stayed the same? What changed? Why?" Model answer and what to look for: There are 12 ways (20c, 10c, 5c coins): 2,1,0; 2,0,2; 1,3,0; 1,2,2; 1,1,4; 1,0,6; 0,5,0; 0,4,2; 0,3,4; 0,2,6; 0,1,8; 0,0,10. Fewest coins: two 20c and one 10c (3 coins). Most: ten 5c coins (10 coins). Systematic method: fix the number of 20c coins (2, then 1, then 0), then the number of 10c coins, then fill with 5c coins. Look for: an organised list, no repeats (the same set of coins in a different order is one way), and the reason for being sure. Extension: what if we also have a 50c coin? (13 ways).
