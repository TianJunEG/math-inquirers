Challenge

1. A bottle full of water weighs 1 kg 200 g. After half of the water is poured out, it weighs 750 g. How heavy is the empty bottle?

2. Mei buys 3 pens and 2 files for $9.20. Each file costs 60¢ more than each pen. How much does one pen cost?

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Use as a pair challenge or in talk time. Ask for the reason every time. Answers: 1) 300 g (half the water weighs 1200 − 750 = 450 g, so all the water is 900 g; the bottle is 1200 − 900 = 300 g). 2) $1.60 (take away the extra 60¢ on each file: $9.20 − $1.20 = $8.00 for 5 pens; 800¢ ÷ 5 = 160¢. A file costs $2.20. Check: $4.80 + $4.40 = $9.20).
