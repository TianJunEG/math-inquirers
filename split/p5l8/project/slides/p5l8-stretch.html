These are the printed Think harder questions A1 to A4 (the same as the workbook). Answers: A1) A = 135° and B = 45°. Adjacent angles of a parallelogram add up to 180°, so A and B make 4 equal parts of 45°: B = 45°, A = 135°. A2) 35° and 35°. 110° cannot be a base angle (two of them would be 220°), so it is the top angle and 180° − 110° = 70° is shared by two equal base angles. A3) AEC = 118° and EAB = 62°. ADC = 56° (opposite angles); DEA = (180° − 56°) ÷ 2 = 62° (DA = DE); AEC = 180° − 62° = 118° (straight line DC); DAB = 180° − 56° = 124° (neighbours in a parallelogram), so EAB = 124° − 62° = 62°. A4) ADE = 150° (90° + 60°). Triangle ADE is isosceles (AD = DE), so DAE = (180° − 150°) ÷ 2 = 15°.
