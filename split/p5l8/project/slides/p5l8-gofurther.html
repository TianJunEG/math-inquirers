These are the printed Go further questions B1 to B3 (the same as the workbook). Answers: B1) 30°. Angles B and C are (180° − 40°) ÷ 2 = 70°. In triangle BCD, BD = BC, so angle BDC = angle C = 70°, which makes angle CBD = 40°. Then ABD = 70° − 40° = 30°. B2) 150°. AE = AB = AD, so triangle ADE is isosceles with angle DAE = 90° − 60° = 30°, which makes angle AED = 75°. In the same way angle BEC = 75°. Angle AEB = 60°. Round E: 360° − 75° − 75° − 60° = 150°. B3) Two sets: 50°, 50°, 80° and 40°, 70°, 70°. (If the top angle is 30° bigger than a base angle: 3 equal parts and 30° make 180°, so base 50°. If a base angle is 30° bigger than the top: top 40°, base 70°.) Make up your own (printed under Go further): Draw a triangle and a parallelogram that share a side.
