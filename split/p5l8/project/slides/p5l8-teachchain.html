Chain: an isosceles triangle inside

D is on BC. DA = DC. Angle C = 35° and angle BAD = 45°. Find angle DAC, ADC, ADB and ABD.

Step 1. Angle DAC = 35°. Reason: DA = DC, so the base angles are equal.

Step 2. Angle ADC = 180° − 35° − 35° = 110°. Reason: angles in a triangle.

Step 3. Angle ADB = 180° − 110° = 70°. Reason: angles on a straight line.

Step 4. Angle ABD = 180° − 45° − 70° = 65°. Reason: angles in a triangle.

So which two angles are equal?" DA = DC, so the equal angles are the ones opposite them: angle C and angle DAC. Click 1: DAC = 35°. Click 2: triangle ADC: 180 − 35 − 35 = 110°. Click 3: B, D, C are on a straight line, so ADB + ADC = 180°: 70°. Click 4: triangle ABD has 45° and 70°, so ABD = 65°. Check: triangle ABC has B = 65, C = 35 and angle BAC = 45 + 35 = 80: 65 + 35 + 80 = 180 ✓. Say: "A chain: each angle helps me find the next, and each has a reason."
