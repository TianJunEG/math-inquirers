Only one angle given: try every case

An isosceles triangle has one angle of 70°. What could the other two angles be?

Case 1: 70° is the TOP angle.

180° − 70° = 110°, and 110° ÷ 2 = 55° each.

55°, 55°, 70°

Case 2: 70° is a BASE angle.

The other base angle is 70° too: 180° − 140° = 40°.

70°, 70°, 40°

Both work, so there are TWO answers. Check each: 70° + 55° + 55° = 180°, and 70° + 70° + 40° = 180°.
