Warm-up: Guess the Angle

No protractor! A paper corner is 90°. Fold it: 45°. Guess A, B, C, D.

A = 120°

B = 30°

C = 150°

D = 90°

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Minutes 3 to 6 (play only 1 or 2 rounds to make room for the warm-up check). Guess the Angle. Children hold up a corner of paper (90°) and a folded corner (45°) to the screen to compare. They write four guesses on whiteboards. Click to reveal each true size. Answers: A = 120°, B = 30°, C = 150°, D = 90°. Ask: "Which was easiest? Why?" (90° is a square corner.) "Is C bigger or smaller than a straight line?" (smaller: a straight line is 180°.) Score: a guess within 10° is a point. Listen for children comparing with 90° and 45°: that is estimating with a benchmark, the same skill as in Lesson 1. Do not use the protractor yet.
