B1: the tick marks tell us which triangles are isosceles. Triangle ABC: AB = AC with top angle 40°, so B = C = 70°. Triangle BCD: BD = BC, so the angles opposite them are equal: angle BDC = angle BCD = 70°. Then angle CBD = 180° − 140° = 40°. Angle ABD = angle ABC − CBD = 70° − 40° = 30°. Q2: AB = AE (equilateral) and AB = AD (square), so AE = AD and triangle ADE is isosceles. Angle DAE = angle DAB − angle EAB = 90° − 60° = 30°, so each base angle is 75°. The same happens on the right: BEC = 75°. The four angles round E add up to 360°: DEA 75° + AEB 60° + BEC 75° + the angle DEC: 360° − 210° = 150°.
