Look for a pattern

17 − 18 = 156 and 18 − 19 = 172. What is 110 − 111?

Step 1. Bottom numbers: 56 = 7 × 8 and 72 = 8 × 9. So 110 − 111 = 1110 (10 × 11).

Step 2. Now add: 156 + 172 = (17 − 18) + (18 − 19).

Step 3. The 18 cancels: 17 − 19 = 963 − 763 = 263.

Each fraction is a difference of two unit fractions, so the middle parts cancel.

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q4). Ask first: "How do you think the bottom numbers are made?" (two neighbouring numbers multiplied: 7 × 8, 8 × 9). Think-aloud: "1/56 + 1/72 looks hard, but each one is a difference. The 1/8 is added in one and taken away in the other, so it disappears." Check: 1/56 + 1/72 = 9/504 + 7/504 = 16/504 = 2/63. Do not show the worksheet fractions: tell the children they will meet a set of fractions with the same trick on page 2.
