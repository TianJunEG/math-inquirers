Why does the multiplication rule work for outfits, but 5 × 5 gives the wrong answer for handshakes between 5 friends?

Sentence starters:

Tool today: Try something simpler. Did it help?
Minutes 78 to 83. One question only. Pairs talk for 90 seconds, then volunteers share. Second question (only if flex is left; otherwise the opener of the next lesson): “How would you change a program that lists every pair so that it lists each handshake once?” Answer: For outfits, every shirt goes with every pair of shorts and a shirt-and-shorts outfit is different from any other, so 3 × 2 counts each outfit once. For handshakes, 5 × 5 = 25 includes each person with themselves (5 cases) and counts A with B and B with A as two, so 25 − 5 = 20 and 20 ÷ 2 = 10. In code, keep only the pairs with a < b. Close: “Today you counted things that would take ages to list: you fixed one choice, multiplied, and halved when you counted twice. Then the computer listed every case to test you. Notice it, test it, explain why.”
