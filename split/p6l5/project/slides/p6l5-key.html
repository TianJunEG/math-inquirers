Key idea: every case, exactly once

Work in order: fix the first choice and run through every second choice. Choices made one after another multiply.

A nested loop does the same: the inner loop runs all the way round for each turn of the outer loop. If order does not matter, check you have not counted each pair twice.

Math Inquirers Level 6 • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Adding the choices instead of multiplying them (4 T-shirts and 3 shorts gives 7 outfits). (2) Counting each handshake twice (7 × 6 = 42) or letting a person shake their own hand. (3) Digit cards: putting 0 at the front of a number, or using the same card twice.
