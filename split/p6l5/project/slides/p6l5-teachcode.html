Let the computer list them: nested loops

The OUTER loop picks the shirt. The INNER loop picks the shorts.

The inner loop runs all the way round for EACH shirt.

It says: 11, 12, 21, 22, 31, 32

3 × 2 = 6 things said ✓

Math Inquirers Level 6 • Notice it. Test it. Explain why.

Teach the code. Share your screen and build it live in Scratch if you can. Think-aloud: “In code, the outer loop picks the shirt and the inner loop picks the shorts. The inner loop goes all the way round for EACH shirt, so the say block runs 3 × 2 = 6 times.” Point at "set shorts to 1": "Why must this go INSIDE the outer loop?" (so the shorts start again from 1 for every shirt; if it were outside, shirt 2 would start at shorts 3 and say 23 and 24, which are not real outfits). "join shirt shorts" sticks the two numbers together: shirt 2 and shorts 1 says 21. Ask: "What would it say with repeat 4 inside?" (3 × 4 = 12 things). Python version: count = 0 for shirt in range(1, 4): for shorts in range(1, 3): print(shirt, shorts) count = count + 1 print(count, "outfits")
