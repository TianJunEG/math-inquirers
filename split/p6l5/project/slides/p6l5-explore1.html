Explore: the bubble tea shop

EXPLORE

  1. A bubble tea shop has 3 teas (milk, green, taro) and 2 toppings (pearls, jelly).
  2. On paper, list every order of 1 tea and 1 topping. How do you know you have them all?
  3. The shop adds sizes M and L. Predict how many orders now, then check.
  4. At the computer: open “Every Order” and put a second loop inside the first so the sprite says every order. (Teas are numbered 1 = milk, 2 = green, 3 = taro; toppings 1 = pearls, 2 = jelly. The sprite says join tea topping, so 21 means green with pearls.)

Hints: Stuck listing: write the first tea, then every topping with it. Then the next tea. Code stuck: drag a second repeat block INSIDE the first one. Which loop should say the topping?
