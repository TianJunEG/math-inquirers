Every outfit: fix one choice, then the next

3 shirts. 2 pairs of shorts. List every outfit.

Fix the red shirt: 2 outfits. Every shirt gets the same 2.

3 groups of 2: 3 × 2 = 6 outfits.

Add 2 caps: each outfit splits in 2. 6 × 2 = 12.

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach. Click 1: the tree appears. Then the three steps, then the caps. Think-aloud: “3 shirts and 2 pairs of shorts. I fix the red shirt and try every pair of shorts: red with black, red with grey. That is 2. Every shirt gets the same 2, so 3 shirts give 3 groups of 2: 3 × 2 = 6. Add 2 caps: each of the 6 outfits splits into 2, so 12.” Name it: "When choices are made one after another, we MULTIPLY. This is called the multiplication rule." Ask: "Why not 3 + 2?" (that counts shirts and shorts, not outfits).
