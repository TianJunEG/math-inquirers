1. A set of dominoes has one domino for every pair of spot numbers from 0 to 6, including doubles such as 3 | 3. How many dominoes are in the set?

2. How many 3-digit numbers have digits that add up to 5? (For example, 203.)

Math Inquirers P6 • Notice it. Test it. Explain why.

Pairs try first, then use the "see it" slide if stuck, then the walk-through. These are also on the Think Harder page (Q6 and Q7). Answers: 1) 28 (7 doubles, plus 6 + 5 + 4 + 3 + 2 + 1 = 21 with two different numbers) 2) 15 (first digit 1: 5 numbers, 2: 4, 3: 3, 4: 2, 5: 1; they are 104, 113, 122, 131, 140, 203, 212, 221, 230, 302, 311, 320, 401, 410, 500)
