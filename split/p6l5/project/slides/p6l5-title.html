LESSON 5 • WEEK 3

Every Possible Way

Counting • nested loops

TODAY WE WILL

Count every possible way without missing one or counting one twice, use the multiplication rule, and make nested loops list every case for us.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Count every possible case without missing one or counting one twice: list in order, use the multiplication rule for choices made one after another, take care with order and with 0 in digit puzzles, count handshakes and grid routes, and test each count with nested loops in code. Materials: Laptop or desktop with Scratch 3 (scratch.mit.edu) open, the starter project “Every Order” (one loop that says each tea), mini whiteboards, digit cards 0 to 9, squared paper. Online: Children share their screen when they test code. The tutor shares the starter project as an .sb3 file in the chat (children use File, Load from your computer; no account needed), and the three starter blocks are also on the slide. Block colours on our slides are simplified; in Scratch, find blocks by the category name on the left, not by colour. Digit cards can be cut from paper. Breakout rooms in pairs for the Explore. Time plan (the exact minutes of this lesson, with a standing flex buffer): opening 0 to 2, sneak-peek puzzles 2 to 6.5, warm-up 6.5 to 13, explore 13 to 26 (paper only), mini-lesson 26 to 35.5 (click to reveal each step and answer), brain break 35.5 to 40.5, worksheet 40.5 to 75 with short teaching before each page and a check-together slide after it, flex 75 to 78 (unscripted: use it for Think harder or catch-up; it is lost first), talk time 78 to 83, exit slip 83 to 86, looking back 86 to 88, close and stamp 88 to 90. Before the lesson: share the starter project “Every Order” as an .sb3 file (a sprite with: set tea to 1, repeat 3: say tea for 1 second, change tea by 1). The sprite says the numbers 1, 2, 3, not the tea names: tell children that teas are numbered 1 = milk, 2 = green, 3 = taro and toppings 1 = pearls, 2 = jelly, so "join tea topping" saying 21 means green with pearls.
