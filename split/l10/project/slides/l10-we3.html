Math Inquirers Level 1 Holiday Program • Notice it. Test it. Explain why.

Worked example: make a table. Think-aloud: "I want the 10th number, so I need to know which place each number is in. A table keeps the places tidy. The rule is add 3: I checked every pair, not just the first. 13 is in place 4. Then 16, 19, 22, 25, 28, 31. Place 10 is 31." Count the places aloud with the children so no one skips one. Common mistake: counting the jumps instead of the places (10 numbers have only 9 jumps). Your turn: 2, 5, 8, 11, 14, 17, 20. The 7th number is 20.
