Station A: coins and patterns

Coins: make 45¢ using exactly 3 coins from 5¢, 10¢, 20¢ and 50¢.

Pattern: 5, 8, 11, 14 … What is the 10th number?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Worked example 1. Model it, then let children try. Answer: Coins: 20¢ + 20¢ + 5¢. Pattern: add 3. Count on: 5, 8, 11, 14, 17, 20, 23, 26, 29, 32, so the 10th is 32.
