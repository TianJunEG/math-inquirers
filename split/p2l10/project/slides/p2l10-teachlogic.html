Logic grid: tick one, cross the rest

Each child buys a different snack. Clue 1: Kai buys roti prata. Clue 2: Lin does not buy chicken rice.

Step 1. Clue 1: tick Kai and roti prata. Cross the rest of his row and the rest of that column.

Step 2. Clue 2: cross Lin and chicken rice. Only kaya toast is left for Lin.

Step 3. Ravi gets the last one: chicken rice. Check both clues ✓

Math Inquirers P2 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q4 is a logic grid with 4 children). Draw the grid. Click order: the clue 1 marks, step 1, the clue 2 marks, step 2, the last tick, step 3. (Or reveal each step first if you prefer.) Think-aloud: "Each child buys a DIFFERENT snack, so each row has exactly one tick and each column has exactly one tick. Clue 1 tells me Kai buys roti prata: tick. So Kai cannot buy anything else, and nobody else can buy roti prata: I cross them. Clue 2: Lin does not buy chicken rice: cross. Look at Lin’s row: only kaya toast is left, tick it, and cross kaya toast for Ravi. Ravi’s row has one empty box left: chicken rice." Check exactly one answer: every row and every column has one tick. Common mistake: ticking without crossing the rest, so the next step is hidden.
