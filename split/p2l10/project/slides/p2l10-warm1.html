Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 0 to 5. Relay review: one card from each of our earlier topics. Read a card, say a child’s name; that child answers and names the next child. Click to reveal each answer in order. A wrong answer gets a friendly “try again”, never a groan. Answers: 740 (biggest digit first; 0 last). 6 (5 + 4 = 9 ones, 2 + 1 = 3 hundreds; the tens must make 7: □ + 1 = 7, so 6; check 365 + 214 = 579). 20 (4, 8, 12, 16, 20). 23 (add 5). 35¢ ($1 = 100¢; 65 + 35 = 100). 3/4 (4 quarters make the whole; 1 eaten, 3 left). Ask after each: "Which lesson does this remind you of?"
