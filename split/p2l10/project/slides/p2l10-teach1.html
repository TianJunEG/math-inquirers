How to start a puzzle

Stuck? Do not just stare. Put the puzzle on paper.

Draw it

Use it for: Before-and-after stories, more than and fewer than, halves.

List it

Use it for: Find every number, every coin set, every way.

Make a table

Use it for: Try 0, 1, 2, 3 … when something changes step by step.

Why? A puzzle is hard to hold in your head. On paper you can see it, check it and explain it.
