Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Minutes 8.5 to 11.5. Three questions, about 30 seconds each: read each aloud, whiteboards up together, then click. No follow-up questions. If a child writes 6045 or 600 045 for question 2, say it as "60 thousand, 0 hundreds, 4 tens, 5 ones". In question 3 the thousands digit was 9, so the ten thousands digit changes too. Do not teach the halfway rule yet. Answers: 7000, 60 045, 60 600. The other two warm-up questions (40 000 + 3000 + 50 + 8; 36 815 to the nearest 1000) are in the Weekly Dose of Thinking Math.
