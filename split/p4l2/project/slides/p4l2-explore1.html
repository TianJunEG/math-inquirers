Explore: what to do

EXPLORE

  1. Take the digit cards 2, 4, 5, 7 and 9.
  2. Make a 5-digit number using each card once. Write it down.
  3. Round it to the nearest thousand. Does it round to 50 000?
  4. Find ALL the numbers that round to 50 000. Which is closest to 50 000?

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Minutes 10 to 15. Pairs work with digit cards 2, 4, 5, 7 and 9 (online: paper cards on camera). Ask for a prediction first: how many numbers will round to 50 000? Let them try numbers freely at first. Common first try: 52 479 (rounds to 52 000) or 54 279 (54 000). Push them towards numbers starting with 4 9. Early finishers: which number you can make is closest to 70 000? (72 459, which is 2459 away: there is no 6 card, so nothing can start 69.)
