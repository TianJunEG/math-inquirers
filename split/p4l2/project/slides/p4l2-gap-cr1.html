ADDED ITEM cr1 (a slide-only addition for the skill gap "Letter sums"; it is not in the printed workbook). TOOL: Guess and check. SAY: Two 2-digit numbers cannot add to more than 198. So what can the first digit of the answer be? ASK: Which letter is that digit? What does the tens column then tell you about P? LISTEN FOR: Q = 1 from the size of the sum, then 2 x P + carry gives a number ending in 1 with a carry, so P = 5. Children who guess P first and test it are using Guess and check well. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: P = 5, Q = 1, R = 9, S = 0. Check: 51 + 59 = 110. WHY: The answer has 3 digits, so its first digit is 1 and Q = 1. The tens column gives P + P + carry = 11, so P = 5 and the carry is 1. The ones column gives Q + R = 10 + S, so 1 + R = 10 + S: R = 9 and S = 0. SAME SKILL, NEW NUMBERS (tutor bank, say it aloud or write it on the board): Each letter is a different digit. TT + UT = TVW. Find T, U, V and W. Answer: T = 1, U = 9, V = 0, W = 2 (11 + 91 = 102).
