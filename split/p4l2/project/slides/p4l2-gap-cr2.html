ADDED ITEM cr2 (a slide-only addition for the skill gap "Letter sums, a longer one"; it is not in the printed workbook). TOOL: Guess and check. SAY: Two 3-digit numbers add to a 4-digit number. What is the biggest the first digit of the answer can be? Start there. ASK: Which letter is the answer's first digit, and what must the hundreds column be to make it? LISTEN FOR: E = 1 first. Then children list possibilities for the hundreds column (D + E + carry) and test with the other columns. A table with one column per letter helps. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: D = 8, A = 3, E = 1, C = 4, B = 0. Check: 883 + 148 = 1031. WHY: E = 1 because 999 + 999 = 1998. Hundreds: D + E + carry makes a number with tens digit B and carry 1, so D + 1 + carry is 10 or more: D = 8 with carry 1 gives 10, so B = 0. The tens column D + C + carry = A + 10 and the ones A + D = E + 10 give A = 3 (3 + 8 = 11) and C = 4.
