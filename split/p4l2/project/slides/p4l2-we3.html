Estimate first, then check

7 boxes each hold 3089 beads. About how many beads is that?

Step 1. Round 3089 to the nearest thousand: 3000.

Step 2. Estimate: 7 × 3000 = 21 000.

Step 3. We rounded DOWN, so the exact answer is a bit MORE. 7 × 3089 = 21 623 ✓

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 1 (Q3 estimates and checks). Draw the bar: 7 equal parts. Think-aloud: "3089 is close to 3000. 7 × 3 thousands = 21 thousands. I rounded each part down by 89, so my estimate is too small, and the real answer is more." Work out 7 × 3089 together in columns if time (21 623). Ask: "If the number were 2950, would the exact answer be more or less than 21 000?" (less: 2950 was rounded up).
