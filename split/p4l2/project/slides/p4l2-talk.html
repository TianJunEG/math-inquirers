Math Inquirers Level 4 Holiday Program • Notice it. Test it. Explain why.

Minutes 80 to 85. Pairs talk for 2 minutes, then share. Answer: Siti is right: 49 999 is only 1 away from 50 000, so it rounds to 50 000 each time (49 999 → 50 000 to the nearest 10 because 9 ones round up). Ravi is wrong: 45 000 is exactly halfway between 40 000 and 50 000, and halfway rounds up, to 50 000. Praise the reasons, not only the answers. TALK TIME RULES: ask for volunteers first; a child may always pass; never call on a child by name to answer; no public tallies, scores or rankings; praise the reason, not the child. If a question uses a mistaken idea (a character who gets it wrong), present it as the character's idea and ask "What would you say to them?" so no child owns the mistake.
