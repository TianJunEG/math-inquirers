LESSON 6 • WEEK 3

Fair or Unfair?

Probability • random numbers

TODAY WE WILL

Measure chance with fractions, decide if a game is fair, and test it by running the game 1000 times in code.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Write a probability as a fraction (ways it can happen out of equally likely outcomes), list all 36 outcomes for two dice, decide whether a game is fair, change a game to make it fair, and run a game 1000 times in code, explaining why the result is close to what we expect but not exact. Materials: Laptop or desktop with Scratch 3 (scratch.mit.edu), two dice per pair (or the tutor’s dice program), a coin, coloured counters and a paper bag, mini whiteboards, tally sheet. Online: Children roll real dice at home; anyone without dice builds the dice program live in the shared Scratch window (pick random 1 to 6, twice) and uses that. This lesson is enrichment: probability is new to most children, so keep it playful. Block colours on our slides are simplified; in Scratch, find blocks by the category name on the left, not by colour. Pairs play the Explore game in breakout rooms and type their tallies into the chat so the group total can be added up. Time plan: warm-up 0 to 10, explore 10 to 25 (play the Dice Race, then pool the results), teaching 25 to 35 (click to reveal each step and answer), brain break 35 to 40, worksheet 40 to 75 with short teaching before each page and a check-together slide after it, talk time 75 to 82, exit ticket 82 to 90. Before the lesson: have the Explore game program ready to share (Scratch, below on the teach-code slide) and a dice program for children without dice.
