Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Write a probability as a fraction (ways it can happen out of equally likely outcomes), list all 36 outcomes for two dice, decide whether a game is fair, change a game to make it fair, and run a game 1000 times in code, explaining why the result is close to what we expect but not exact.
