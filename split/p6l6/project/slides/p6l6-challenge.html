Challenge

1. Mei and Ali each roll one dice. Mei wins if her number is bigger. Ali wins if his number is bigger or the same. Is the game fair? What is the probability that Mei wins?

2. Spinner A has 3 equal parts: 1, 2, 3. Spinner B has 4 equal parts: 1, 2, 3, 4. Spin both and multiply. Even wins if the answer is even, Odd wins if it is odd. Is the game fair?

Math Inquirers P6 • Notice it. Test it. Explain why.

Pairs try first, then use the "see it" slide if stuck, then the walk-through. These are also on the Think Harder page (Q6 and Q7). Answers: 1) Not fair. Mei wins 15/36 = 5/12; Ali wins 21/36 = 7/12 (15 bigger + 6 the same). Fair version: the same number means roll again. 2) Not fair. There are 3 × 4 = 12 outcomes; the answer is odd only when both are odd: 2 × 2 = 4 ways. P(Odd) = 4/12 = 1/3, P(Even) = 8/12 = 2/3.
