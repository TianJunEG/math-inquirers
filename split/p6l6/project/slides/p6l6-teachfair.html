Is the game fair?

Flip two coins. Ali wins if they are the same. Ben wins if they are different.

Not 3 outcomes (two heads, two tails, one of each)! HT and TH are different.

4 equally likely outcomes: P(Ali) = 2/4, P(Ben) = 2/4

Same probability of winning: the game is fair ✓

Code (Q5): each coin needs its own pick random; a = b counts Ali’s wins; expect about 500.

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 57.5 to 60.5. Teach before worksheet page 2 (Q4, the Difference Game: do not do it here; the bottom panel is the Q5 code plan, folded in). For the code: each coin needs its own random number (one pick random for both coins would make them always the same); if time, run it: answers near 500 (e.g. 489, 512) confirm the game is fair. Ask first: "Fair or not? Thumbs up or down." Many say Ali wins only 1/3 (two heads, two tails versus one of each). Use two different coins (a 10¢ and a 20¢) so HT and TH are clearly different. Then: "How could we change an unfair game to make it fair?" (change which outcomes win, or give different points).
