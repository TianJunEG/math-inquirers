ADDED ITEM cr1 (a slide-only addition for the skill gap "Letter sums"; it is not in the printed workbook). TOOL: Guess and check. SAY: Three digits plus three digits make 4 digits. What does that tell you about the first letter of the answer? ASK: Which column will you look at second, and why? LISTEN FOR: A = 1 from the size of the sum. Then the hundreds column (C + E + carry) gives B and a carry. Accept a table of tries. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: A = 1, B = 0, C = 8, D = 9, E = 3. Check: 888 + 131 = 1019. WHY: The sum is less than 2 000, so A = 1. Ones column: C + A = D (8 + 1 = 9, no carry). Tens column: C + E = 10 + A, so C + E = 11 and the carry is 1. Hundreds column: C + A + 1 = 10 + B, so C = 8 and B = 0, and then E = 3.
