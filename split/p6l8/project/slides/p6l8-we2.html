Caesar code: letters are numbers

Letters on a 26-hour clock: A = 0, B = 1 … Z = 25. Code ZOO with shift 5.

Step 1. Z = 25. 25 + 5 = 30. There is no letter 30, so wrap round: 30 mod 26 = 4, and 4 is E.

Step 2. O = 14. 14 + 5 = 19, and 19 is T. Second O: also T.

ZOO becomes ETT code number = (letter number + shift) mod 26

Math Inquirers P6 • Notice it. Test it. Explain why.

Click through. Think-aloud: "To code Z with shift 5: Z is 25. 25 + 5 = 30. There is no letter 30, so I wrap round: 30 − 26 = 4, and 4 is E." Point out the highlighted letters on the strip: Z is above E, O above T. Ask: "Which letters wrap round with shift 5?" (V, W, X, Y, Z become A to E). Say: this is called a Caesar cipher after Julius Caesar, who used a shift of 3 to send orders. Optional Python version (for children who already know Python): alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ" message = "MEET AT THE MRT" shift = 3 code = "" for letter in message: if letter in alphabet: n = alphabet.index(letter) # A is 0 m = (n + shift) % 26 # % is mod code = code + alphabet[m] else: code = code + letter # keep spaces print(code) Run as it is, it prints PHHW DW WKH PUW (MEET AT THE MRT with shift 3). Set shift = -3 and message = "PHHW DW WKH PUW" to decode (Python % gives a answer between 0 and 25 even for negative numbers).
