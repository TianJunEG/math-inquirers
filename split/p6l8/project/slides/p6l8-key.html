Key idea: wrap round like a clock

n mod m is the remainder when n is divided by m. On a clock with m numbers, counting past the end wraps round to the start.

Caesar code: code number = (letter number + shift) mod 26. Decode: shift back (add 26 if you go below 0), or shift forward by 26 − shift.

Math Inquirers P6 • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Off by one: counting A as 1 in the maths (we use A = 0, Z = 25), or forgetting that Scratch’s list starts at item 1. (2) Not wrapping round: writing a number bigger than 25 (or below 0 when decoding) instead of taking away or adding 26. (3) Calendars: counting today as day 1 (Saturday + 2 days is Monday, not Sunday), or giving the quotient instead of the remainder for mod.
