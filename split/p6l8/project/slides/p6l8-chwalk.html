Q1: the × 2 code

A = 0, and 0 × 2 = 0, so A becomes A.

N = 13, and 13 × 2 = 26, and 26 mod 26 = 0: A again!

Two letters give A, so a code A could be A or N.

Every code number is even: only 13 code letters used.

Q2: the × 3 code

C = 2: 2 × 3 = 6 = G. A = 0: 0 = A.

B = 1: 1 × 3 = 3 = D. So CAB is GAD.

Could two letters match? That needs 3 × (difference) to be a multiple of 26.

It never works: 3 and 26 share no factor. All 26 differ ✓
