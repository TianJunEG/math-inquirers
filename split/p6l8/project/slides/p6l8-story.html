Story break: Al-Kindi

Al-Kindi • about 801 to about 873 • Iraq (born in Kufa, worked in Baghdad)

Al-Kindi was born in Kufa, in what is now Iraq, about 1,200 years ago, and he worked in Baghdad in the time of the House of Wisdom, where scholars studied and translated books. He wrote on many subjects, including maths and the Hindu-Arabic numbers. Around the year 850 he wrote A Manuscript on Deciphering Cryptographic Messages. It is the earliest explanation we know of for breaking a code by counting letters. In any language some letters are used more often than others. So count the letters in the coded message, then match the most common coded symbol to the most common letter in the language. The manuscript was lost for a long time before a modern scholar found it in an archive in Istanbul.

Try it (optional, no pressure)

A message is in English and every letter was shifted by the same amount. The commonest letter in the code is L. If it stands for E, what was the shift? (A = 0, B = 1, ... Z = 25, and use mod 26.)

Link to today: A shift code uses mod 26, and Al-Kindi's letter counting is the way to break one. The Try it is optional and nobody is marked: children can think quietly, tell a partner, or pass.
