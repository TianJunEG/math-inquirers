1. Mei makes a new code: multiply each letter number by 2, then take mod 26. Why can her friend not always decode it?

2. Ben’s code multiplies each letter number by 3, then takes mod 26. Code the word CAB. Do two letters ever get the same code letter?

Math Inquirers P6 • Notice it. Test it. Explain why.

Pairs try first, then use the "see it" slide if stuck, then the walk-through. Answers: 1) Two letters can give the same code letter: A (0) and N (13) both give 0 = A (13 × 2 = 26). So every code letter could stand for two different letters. 2) GAD (C = 2 gives 6 = G, A = 0 gives 0 = A, B = 1 gives 3 = D). No: all 26 letters get different code letters, because 3 and 26 have no common factor.
