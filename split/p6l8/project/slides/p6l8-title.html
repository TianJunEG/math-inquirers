LESSON 8 • WEEK 4 • MATHS + CODE

Secret Codes

Clock (modular) arithmetic

TODAY WE WILL

Use clock arithmetic (mod) to solve time and calendar puzzles, make and break secret codes, and build a code machine in Scratch.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Do clock arithmetic (counting past the end wraps round to the start), use n mod m as the remainder when n is divided by m, solve clock and calendar puzzles with mod 12 and mod 7, code and decode Caesar ciphers with letter numbers (A = 0 … Z = 25, code = (letter + shift) mod 26), crack a code, and test it all with a Scratch program that uses a list of letters and mod. Materials: A laptop or desktop with Scratch 3 open (the tutor builds and shares a starter project with a list called alphabet holding A to Z; no .sb3 file exists in this repository, so build it beforehand), mini whiteboards, paper for code strips, scissors. Online: Children make their code strips on paper and hold them to the camera. Children hold up their coded name on paper to the camera, or the tutor reads out the coded names; partners decode on paper. Pairs use breakout rooms for the coding part; the driver shares the screen. Starter project: the tutor shares an .sb3 file (not a link only) containing the list alphabet with A to Z already filled in, and the loop already built; children add the three cipher blocks. Block colours on our slides are simplified; in Scratch, list blocks are red-orange (Variables palette) and you find blocks by the category name on the left, not by colour. Scratch set-up: before the lesson, build the starter project once from the whole-machine slide: a list called alphabet holding the letters A to Z (add each letter with the add to list block), and everything in the machine except the 3 cipher blocks. Save it as an .sb3 file and share the FILE, not only a link, so children load it with File, Load from your computer. Scratch lists count from item 1, so letter number n (A = 0) is item n + 1. The mod block is in the Operators menu. List blocks in Scratch are red-orange and live in the Variables palette; our slides draw them as simple coloured shapes, so find blocks by the category name on the left, not by colour. Time plan (the exact minutes of this lesson, with a standing flex buffer): opening 0 to 2, sneak-peek puzzles 2 to 6, warm-up 6 to 11.5, explore 11.5 to 26, mini-lesson 26 to 37 (click to reveal each step and answer), brain break 37 to 42, worksheet 42 to 73 with short teaching before each page and a check-together slide after it, flex 73 to 77 (unscripted: use it for Think harder or catch-up; it is lost first), talk time 77 to 83, exit slip 83 to 86, looking back 86 to 88, close and stamp 88 to 90.
