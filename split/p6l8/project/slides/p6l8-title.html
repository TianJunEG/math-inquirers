LESSON 8 • WEEK 4 • MATHS + CODE

Secret Codes

Clock (modular) arithmetic

TODAY WE WILL

Use clock arithmetic (mod) to solve time and calendar puzzles, make and break secret codes, and build a code machine in Scratch.

Math Inquirers Level 6 • Notice it. Test it. Explain why.

Objective: Do clock arithmetic (counting past the end wraps round to the start), use n mod m as the remainder when n is divided by m, solve clock and calendar puzzles with mod 12 and mod 7, code and decode Caesar ciphers with letter numbers (A = 0 … Z = 25, code = (letter + shift) mod 26), crack a code, and test it all with a Scratch program that uses a list of letters and mod. Materials: A laptop or desktop with Scratch 3 open (the tutor builds and shares a starter project with a list called alphabet holding A to Z; no .sb3 file exists in this repository, so build it beforehand), mini whiteboards, paper for code strips, scissors. Online: Children make their code strips on paper and hold them to the camera. Children hold up their coded name on paper to the camera, or the tutor reads out the coded names; partners decode on paper. Pairs use breakout rooms for the coding part; the driver shares the screen. Starter project: the tutor shares an .sb3 file (not a link only) containing the list alphabet with A to Z already filled in, and the loop already built; children add the three cipher blocks. Block colours on our slides are simplified; in Scratch, list blocks are red-orange (Variables palette) and you find blocks by the category name on the left, not by colour. Scratch set-up: before the lesson, build the starter project once from the whole-machine slide: a list called alphabet holding the letters A to Z (add each letter with the add to list block), and everything in the machine except the 3 cipher blocks. Save it as an .sb3 file and share the FILE, not only a link, so children load it with File, Load from your computer. Scratch lists count from item 1, so letter number n (A = 0) is item n + 1. The mod block is in the Operators menu. List blocks in Scratch are red-orange and live in the Variables palette; our slides draw them as simple coloured shapes, so find blocks by the category name on the left, not by colour. Time plan: warm-up 0 to 10, explore 10 to 25, teaching 25 to 35 (click to reveal each step and answer), brain break 35 to 40, worksheet 40 to 75 with short teaching before each page and a check-together slide after it, talk time 75 to 82, exit ticket 82 to 90.
