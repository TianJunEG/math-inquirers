ADDED ITEM cr2 (a slide-only addition for the skill gap "Letters stand for digits, a longer one"; it is not in the printed workbook). TOOL: Guess and check. SAY: What is the first letter of the answer? Then look for a column where a letter added to itself or to a known digit has only a few possible answers. ASK: Which letter must be 0? Why? How do you check your answer against every column? LISTEN FOR: A = 1 from the size of the sum. Ones: E + D = 11. Tens: D + C + 1 = E. Combine them: 2 x D + C = 10. Children use a table of tries for C and D. Accept any organised method that checks all four columns. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: B = 9, D = 5, E = 6, A = 1, C = 0. Check: 956 + 105 = 1061. WHY: A = 1. Ones: E + D = 10 + A = 11. Tens: D + C + 1 = E. So 2D + C = 10. Hundreds: B + A = 10 + C, so B = 9 + C and C = 0, D = 5, E = 6, B = 9. Check: 956 + 105 = 1061 and ACEA reads 1, 0, 6, 1. This is the only solution (checked by a script).
