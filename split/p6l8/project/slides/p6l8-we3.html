Decoding: add 26 if you go below 0

Decode AEB. It was made with shift 4.

Step 1. A = 0. 0 − 4 = −4: below 0. Add 26: −4 + 26 = 22, and 22 is W.

Step 2. E = 4. 4 − 4 = 0, and 0 is A. B = 1. 1 − 4 = −3, + 26 = 23, and 23 is X.

AEB is WAX

The Scratch code machine runs these 3 blocks for each letter. Lists start at item 1, so letter n is item n + 1.

Decoding with shift 4 is the same as coding with shift 22, because 26 − 4 = 22. The blocks run once for each letter of the message: "for each letter" is a repeat loop.
