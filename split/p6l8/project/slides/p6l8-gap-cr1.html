ADDED ITEM cr1 (a slide-only addition for the skill gap "Letters stand for digits"; it is not in the printed workbook). TOOL: Guess and check. SAY: A cipher replaces letters with other symbols, and so does this puzzle. Start with the column that cannot be wrong: the answer has 4 digits. ASK: What is the first letter of the answer? Which column do you do next, and what do you try? LISTEN FOR: A = 1. The ones and tens digits of the answer are the same letter, B, which gives two equations to test. Make a table of tries for C and E. This is Guess and check, not Spot the pattern, even though it sits in the Secret Codes lesson. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: D = 5, E = 7, C = 3, A = 1, B = 4. Check: 573 + 771 = 1344. WHY: A = 1 (two 3-digit numbers add to less than 2 000). Ones: C + 1 = B, so there is no carry. Tens: E + E = 10 + B with a carry of 1. Hundreds: D + E + 1 = 10 + C. So B = C + 1 and 2E = 11 + C, which needs C odd. C = 1 is used by A; C = 3 gives E = 7, B = 4 and D = 5; C = 5 gives D = B = 6 and C = 7 gives D = C, which break the rule. Check: 573 + 771 = 1344.
