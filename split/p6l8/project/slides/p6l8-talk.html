Second question: Ali says decoding shift 3 is the same as coding again with shift 23. Is he right? Why? Answer: A shift of 26 moves every letter once round the whole 26-letter clock, so each letter lands back on itself (26 mod 26 = 0). Ali is right: shifting back 3 and shifting forward 23 land on the same letter, because 23 + 3 = 26 is a full turn. For example D (3): 3 − 3 = 0 = A, and 3 + 23 = 26, 26 mod 26 = 0 = A.
