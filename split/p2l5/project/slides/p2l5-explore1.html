Explore: what to do

EXPLORE

  1. Pick one × card and one + or − card. Put them in a row: that is your machine.
  2. Secretly choose a start number. Run it through both cards. Say only the OUT.
  3. Your partner works backwards to find your start number. Check it together.
  4. Swap the order of the two cards. Same start number. Is the OUT the same?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 8 to 14. Pairs build a two-step machine from the cards (one × card from × 2, × 3, × 4, × 5, × 10, and one + or − card). Partner A chooses a start number (keep it from 1 to 10) and says only the OUT. Partner B works backwards, then they check by going forwards. Then they swap the order of the cards and run the SAME start number. Online: the tutor runs the machine on the slide and children work back on whiteboards; then pairs in breakout rooms make their own. Prediction first: "× 2 then + 6, start 4. Then + 6 then × 2, start 4. Same OUT?" Thumbs up or down.
