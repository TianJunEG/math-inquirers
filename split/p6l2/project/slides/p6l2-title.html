LESSON 2 • WEEK 1 • MATHS + CODE

Prime Hunters

Primes, factors and prime factorisation • if, mod and a counter

TODAY WE WILL

Find factors in pairs, test whether a number is prime, split numbers into primes, and teach a computer to count factors with mod.

Math Inquirers Level 6 • Notice it. Test it. Explain why.

Objective: Find all the factors of a number using factor pairs, decide whether a number is prime by testing small divisors, write a number as a product of primes with a factor tree, use mod (the remainder), if and a counter in code to count factors, and explore Goldbach pairs and numbers with exactly 3 factors. Materials: Laptop or desktop with Scratch 3 open, a printed 1 to 100 grid (or squared paper), two coloured pencils, mini whiteboard, workbook. Optional: a Python editor for children who already know Python. Online: Share the 1 to 100 grid on screen and annotate it while children work on their own printed or hand-drawn grid. Build the prime checker together in your shared Scratch window; the blocks are also on the slide. Block colours on our slides are simplified; in Scratch, find blocks by the category name on the left, not by colour. Children hold their grid up to the camera at minute 22. Time plan: warm-up 0 to 10, explore 10 to 25 (the sieve by hand), teaching 25 to 35 (click to reveal each step and answer), brain break 35 to 40, worksheet 40 to 75 with short teaching before each page and a check-together slide after it (page 1 is the maths, page 2 is the code and the puzzles), talk time 75 to 82, exit ticket 82 to 90. Python: the optional Python version of each program is in the notes of the code slides and in the workbook Python corner.
