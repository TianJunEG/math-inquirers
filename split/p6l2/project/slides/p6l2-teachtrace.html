Minutes 54 to 57. Teach before worksheet page 2 (Q3, and the Q6 plan as the second panel). Walk through: d starts at 1; each time round the loop we test 8 mod d, maybe add 1 to count, then add 1 to d. Rows reveal on click. Row 3: 8 mod 3 = 2 (8 = 3 × 2 + 2), not 0, so count stays 2. Ask: "Why is the answer 3 and not 4?" (the loop only goes up to d = 4; 8 has more factors, 8 itself, but it is not tested.) Python (optional): count = 0 for d in range(1, 5): if 8 % d == 0: count = count + 1 print(count) Prints 3. For Q6 (the blocks for the factors of 40, in a jumble in the workbook) point out three things in order: set up (hat and set d), the loop, and what goes inside the loop (if, then say, then change d). With plain say the loop is so fast that only the last number stays on screen, so use say for 1 seconds. The classic bug: change d by 1 inside the if, so d gets stuck on a number that is not a factor.
