Plan your code: say every factor of 20

Step 1. d starts at 1 and tests every number up to 20.

Step 2. The if block goes INSIDE the repeat; change d is inside too, but outside the if.

It says 1, 2, 4, 5, 10, 20 (one per second)

If change d were inside the if, d would get stuck on 3: 20 mod 3 is not 0, so it would never move on.

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q6). The workbook puts the blocks in a jumble for factors of 40. Point out the three things in order: set up (hat and set d), the loop, and what goes inside the loop (if, then say, then change d). With plain say (no seconds) the loop is so fast that only the last number stays on screen, so use say for 1 seconds. The classic bug: change d by 1 inside the if.
