Q1: one column at a time

Ones: 7 + the ones box = 10, so it is 3. Carry 1.

Hundreds: the hundreds box + 4 + 1 = 10, so it is 5.

Tens: the two tens boxes + 1 = 10, so the two add to 9.

0 + 9, 1 + 8 … 9 + 0: 10 ways (507 + 493 … 597 + 403)

Q2: compare the clues

Box A + Box B = 250 and Box B + Box C = 350: Box C has 100 more than Box A.

Box A + Box C = 400. Take away the extra 100: 300.

Half of 300 is 150: Box A has 150, Box C has 250.

Box B: 250 − 150 = 100. Check: 100 + 250 = 350 ✓
