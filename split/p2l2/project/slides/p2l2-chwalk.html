Q1: one column at a time

Ones: 7 + □ = 10, so □ = 3. Carry 1.

Hundreds: □ + 4 + 1 = 10, so □ = 5.

Tens: □ + □ + 1 = 10, so the two add to 9.

0 + 9, 1 + 8 … 9 + 0: 10 ways (507 + 493 … 597 + 403)

Q2: compare the clues

A + B = 250 and B + C = 350: C is 100 more than A.

A + C = 400. Take away the extra 100: 300.

Half of 300 is 150: A = 150, C = 250.

B = 250 − 150 = 100. Check: 100 + 250 = 350 ✓
