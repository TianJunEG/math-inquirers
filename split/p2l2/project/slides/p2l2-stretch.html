Stretch

1. Find the missing digits: 6□5 + □7□ = 900

2. The same number goes in both boxes: □ + □ + 250 = 750. What is it?

3. Adding 99 is the same as adding 100, then taking away 1. Use it: 456 + 99 = ?

Math Inquirers P2 Holiday Program • Notice it. Test it. Explain why.

Answers: 1) 625 + 275 = 900 (ones 5 + 5 = 10; tens 2 + 7 + 1 = 10; hundreds 6 + 2 + 1 = 9). 2) 250 (750 − 250 = 500, and 250 + 250 = 500). 3) 555 (456 + 100 = 556, then 556 − 1 = 555).
