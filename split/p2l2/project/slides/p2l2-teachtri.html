Magic triangles: think about the corners

Put 11, 12, 13, 14, 15 and 16 in the circles so each side adds up to 42.

Step 1. Each corner is on TWO sides. A big total needs big corners: try 14, 15, 16.

Step 2. 14 + A + 15 = 42, so A = 13. 15 + B + 16 = 42, so B = 11.

Step 3. 16 + C + 14 = 42, so C = 12. Every number used once ✓
