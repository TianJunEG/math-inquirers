Explore: printer race

EXPLORE

  1. Printer A prints 72 pages in 4 minutes. Printer B prints 50 pages in 2 minutes.
  2. Make a rate table for each printer: 1, 2, 4 and 10 minutes.
  3. Which printer is faster? Show how you know.
  4. Predict, then work out: how long do both together take for 430 pages?

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Minutes 10 to 15. Pairs build a rate table for each printer. Ask them to predict first: which is faster, and how long for the 430-page job together? Many say A, because 72 is more than 50. Let them test it: in 4 minutes A prints 72 pages but B prints 100. Hint: how many pages in 1 minute? Early finishers: how many pages should go to each printer so both finish at the same time? (A 180, B 250: 10 minutes each.)
