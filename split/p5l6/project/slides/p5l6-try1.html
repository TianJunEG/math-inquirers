Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Whiteboards up together, then click. a) $3.20 / 4 = 80 cents each; 7 x 80 = $5.60. b) 135 / 15 = 9. c) 4 for $2.80 is 70 cents each; 6 for $4.50 is 75 cents each, so the smaller pack is cheaper. Ask for c: "Why might a bigger pack still cost more per item?" (not all shops give a discount for a bigger pack).
