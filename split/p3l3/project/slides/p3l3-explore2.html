Explore: talk about it

1. Which tables made the same shape?

2. Why does the 6s shape never touch an odd digit?

3. Predict: which table makes the same shape as the 3s? Test it.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 15 to 25. Let pairs keep working, then gather them for these three questions. Take ideas before giving any answer and ask "How could we test that?" Answers: 1) The 4s and the 6s make the same 5-pointed star, going round opposite ways (4, 8, 2, 6, 0 and 6, 2, 8, 4, 0). The 2s and the 8s make the same 5-sided shape. 2) Every answer in the 6 times table is even: 6 groups can always be put into 3 pairs of groups, so nothing is left over. 3) The 7s, because 3 + 7 = 10, just like 4 + 6 and 2 + 8. Let a pair test it on a new circle. Keep the circles: we use last digits again in the teaching.
