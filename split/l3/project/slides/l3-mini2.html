Count by 5s

A row has 5 faces and another row has 5 faces. Count: 5, 10.

Then add the extra faces.

Try: 5, 10, 15, then 3 more. How many?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Worked example 2. Ask children to explain each step in their own words. Key = 1 child. Count by 5s to total quickly. If everyone had one vote, the total is the number of children. Answer: 18.
