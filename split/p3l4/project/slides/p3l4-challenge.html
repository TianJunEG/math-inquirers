Challenge

1. Mei and Siti had the same number of stickers. Mei gave away 36 and Siti gave away 108. Now Mei has 4 times as many as Siti. How many stickers did each girl have at first?

2. A pencil box and 3 pens cost $25 altogether. The pencil box costs $5 more than one pen. How much does one pen cost?

Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Pairs try first, then use the "see it" slide if stuck, then the walk-through. Answers: 1) 132 each. Now Siti has 1 unit and Mei 4 units; Siti gave away 72 more than Mei, so 3 units = 72 and 1 unit = 24; Siti had 24 + 108 = 132 (Mei 96 + 36 = 132). 2) $5: take away the extra $5, then 4 equal pen units = $20; the box costs $10.
