TALK TIME

How did swapping help you with the balance puzzles? Why is a table useful for jug puzzles?

Sentence starters:

“I started by …” “I noticed that …” “I know because …” “Pass.”

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 72 to 80. Pairs talk for 2 minutes, then share. Also ask: "How do you count on past the hour?" Listen for: a level balance means the two sides weigh the same, so the melon can be swapped for 2 apples (or 400 g) and the scale stays level. A table shows how much is in each jug after every pour, so we can check every step. Past the hour: count on to the o’clock first (4:50 to 5:00 is 10 minutes), then count the rest. Praise the reasons, not only the answers. Talk time rules: you choose volunteers first ("Who would like to share?"); never cold-call a child by name; any child may say pass; no public tallies, scores or rankings.
