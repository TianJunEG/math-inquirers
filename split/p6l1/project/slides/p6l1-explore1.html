EXPLORE

  1. Build matchstick triangles in a row: pattern 1 has 1 triangle, pattern 2 has 2, pattern 3 has 3.
  2. Count the sticks in each pattern. Make a table.
  3. Predict the sticks in pattern 10 and in pattern 100. Do not build them!
  4. Check pattern 10 in Scratch with a loop and a variable.

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 10 to 15. Pairs build with matchsticks (online: draw the sticks as lines). Insist on a written prediction for pattern 100 BEFORE anyone opens Scratch. Then Scratch: make a variable called sticks; blocks: when green flag clicked, set sticks to 3, repeat 9, change sticks by 2, say sticks. It says 21 (pattern 10). Ask: "Why repeat 9 and not 10?" Python (optional, for children who know it): sticks = 3, then for i in range(9): sticks = sticks + 2, then print(sticks). Prints 21.
