Difference, times table, compare, check.

c 1, 8, 15, 22, …

Math Inquirers P6 • Notice it. Test it. Explain why.

Whiteboards. a) Compare with 5, 10, 15, 20: 1 less, so 5n − 1; 500 − 1 = 499. b) 2, 4, 6, 8: 8 more, so 2n + 8; 208. c) 7, 14, 21, 28: 6 less, so 7n − 6; 694. Check c with the 4th term: 28 − 6 = 22. Watch for children writing 7n + 1 (they added the 1st term instead of comparing).
