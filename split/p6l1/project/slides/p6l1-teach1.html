Term-to-term rule: add 2. Good for the NEXT term.

The difference is 2, so compare with the 2 times table. Each term is 5 more.

Rule for the nth term: 2 × n + 5, written 2n + 5. Good for ANY term: the 50th is 2 × 50 + 5 = 105.

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach. n means the position (1st, 2nd, 3rd …). Think-aloud: "Add 2 each time. That gets me the next term, but for the 50th I would add 2 forty-nine times. The difference is 2, so I write the 2 times table underneath (click). Every term is 5 more than the 2 times-table number (click). So the term in position n is 2 × n + 5. In algebra we write 2n + 5, the same letter idea you used for the PSLE." Check with n = 3: 2 × 3 + 5 = 11, which matches.
