Ali says the 100th term of 7, 10, 13, … is 7 + 3 × 100 = 307. Is he right? Explain with a rule, a picture or code.

Sentence starters:

“I noticed that …” “I tested it by …” “I know because …”

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 70 to 80. Pairs talk for 2 minutes, then share. Listen for: No. The 1st term is already 7 before any jump, so the 100th term is only 99 jumps away: 7 + 3 × 99 = 304. The rule 3n + 4 gives 304 too. Then ask: "When is the rule better than adding on? When is code better than both?" (The rule is fastest for one far term; code is best for listing many terms or checking.)
