Think harder: Sums that cancel

Tool: Spot the pattern

(a) Work out 1/3 − 1/4. Compare it with 1/(3 × 4).

(b) Find 1/(3 × 4) + 1/(4 × 5) + 1/(5 × 6) + ... + 1/(9 × 10).

(a) 1/12. It is the same as 1/(3 × 4).

(b) 7/30.

SAY: Write each fraction in (b) as a difference, like the one you found in (a). Then write the whole sum out in a line and look at what is left. ASK: Which terms cancel? Which two terms are left at the end? LISTEN FOR: Each term 1/(n x (n + 1)) = 1/n - 1/(n + 1). The sum is 1/3 − 1/4 + 1/4 − 1/5 + ... + 1/9 − 1/10, so only 1/3 − 1/10 is left.
