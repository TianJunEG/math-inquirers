Math Inquirers P2 Holiday Program • Notice it. Test it. Explain why.

Whiteboards up together, then click. a) 3 equal parts, 2 shaded: 2/3 shaded, 1/3 not shaded. b) 12 equal parts (twelfths); count the shaded ones carefully, they are not next to each other: 5, so 5/12 shaded and 7/12 not shaded (5 + 7 = 12). c) The trap: 3 parts, 1 shaded, but the parts are not the same size, so the shaded part is NOT one third. Ask: "What would we need to change to make it thirds?"
