Test it like a detective

Known answer

Pick an input you worked out by hand.

e.g. Prime or Not? with 7: it must say Prime!

Edge case

Try the smallest, 0, 1 or the biggest.

e.g. Prime or Not? with 1: 1 factor, so Not prime ✓

Random programs

Run it several times. Close, not exact.

e.g. Lucky Seven: near 167 each time

Math Inquirers P6 • Notice it. Test it. Explain why.

(it is the only whole number with exactly 1 factor; a program that counts badly might call it prime). "If Lucky Seven said 400, what would you think?"
