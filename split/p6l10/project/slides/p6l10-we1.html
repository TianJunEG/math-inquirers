Starter A: Mystery Machine

The maths

OUT = 3n + 4. Backwards: take away 4, then divide by 3.

Test it

If n is 5, it must show OUT: 19. Type 5: “You cracked it!”

Twist ideas

A different rule each time; keep a score; allow negative numbers.

Math Inquirers P6 • Notice it. Test it. Explain why.

Starter A (Lesson 4 idea). Run it on screen. Think-aloud: “Mystery Machine: the program picks n, works out 3n + 4 and shows it. If it shows 19, I go backwards: 19 − 4 = 15, 15 ÷ 3 = 5. Before I trust the program, I test it with a number I already know: if n is 5 it must show 19.” Note: Scratch uses * for ×. "answer" is what the player typed. The worksheet (Q4a) asks for a different test, n = 9, so do not reveal it. 7 blocks. Python version (optional): import random n = random.randint(1, 20) out = n * 3 + 4 print("My machine does x 3, then + 4.") print("Out came", out) guess = int(input("What went in?
