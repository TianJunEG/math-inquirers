Key idea: maths first, then code to test it

Work out the answer by hand first. Then the program is a test: if it agrees with you, you are probably both right; if not, find out which one is wrong.

A good showcase: show the puzzle, run it, show a test you knew the answer to, and explain why it works.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for while children build: (1) Coding before working out the maths, so there is no way to tell whether the output is right. (2) Testing only once, or only with the value the program happened to show, instead of a value worked out by hand (and an edge case such as 1 or 0). (3) Showcase: reading the code block by block instead of explaining the maths puzzle and why the program works.
