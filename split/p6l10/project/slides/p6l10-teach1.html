From puzzle to program

Every program you build today follows the same four steps.

1

Maths first

Pick a puzzle. Work out its answer by hand.

2

Blocks

Input → rule → check → output. Under 15 blocks.

3

Test it

Use a value you already know the answer to.

4

Twist

Change the rule, add a score, or a level 2.

The program is a test of your maths. If they agree, both are probably right.

Math Inquirers P6 • Notice it. Test it. Explain why.

Teach. Click each card. Say: "A program that shows an answer you could not check is not a puzzle, it is a mystery box. So the maths always comes first." Then the three starters, each about one minute. Children do not copy them yet: they choose one at the planning stage after the break.
