Adding a negative moves left

In code we write "change temp by −4". That ADDS −4. It moves the number 4 to the LEFT.

Step 1. 1 + (−4) is the same as 1 − 4. Both land on −3.

Adding a negative = taking away. 7 + (−2) = 7 − 2 = 5

Math Inquirers P6 • Notice it. Test it. Explain why.
