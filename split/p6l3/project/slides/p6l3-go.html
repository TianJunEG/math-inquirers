What if ...?

What if the thermometer program starts at 5 and repeats 20 times (change temp by −3 each time)? Predict the last number. Which repeat number first gives a number below −30?

−55 (5 − 3 × 20). Below −30 first happens at repeat 12: 5 − 36 = −31 (repeat 11 gives −28).
