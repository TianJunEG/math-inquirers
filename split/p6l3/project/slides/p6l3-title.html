LESSON 3 • WEEK 2

Below Zero

Negative numbers • Code: a sprite on a number line

TODAY WE WILL

Use a number line to compare, add and subtract negative numbers, and make a variable in code go below zero.

Math Inquirers P6 • Notice it. Test it. Explain why.

Objective: Order and compare negative numbers on a number line; add and subtract with negative numbers by moving along the line (temperature, lifts, sea level); use "change by" a negative number in code and trace a variable that goes below 0. Materials: laptop or desktop with Scratch 3 open (scratch.mit.edu, no log-in needed), mini whiteboard and marker, workbook, pencil. Tutor: this deck, Scratch open for screen share. Online set-up: children keep Scratch in one browser tab and the video call in another; ask them to rename the sprite "Dot" so nobody is distracted by costumes. Children share their screen only when asked. Type the minus sign with the keyboard minus key (the hyphen); do not copy and paste a number from the slide or chat, because the slide uses a different minus character that Scratch will not accept. Block colours on our slides are simplified; in Scratch, find blocks by the category name on the left, not by colour. Time plan: warm-up 0 to 10, explore at the computer 10 to 25, teaching 25 to 35 (click to reveal each step and answer), brain break 35 to 40, worksheet 40 to 75 with short teaching before each page and a check-together slide after it, talk time 75 to 82, exit ticket 82 to 90.
