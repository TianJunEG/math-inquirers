Explore: the stage is a number line

EXPLORE AT THE COMPUTER

  1. Set x to 0. Your sprite (call it Dot) is in the middle.
  2. Predict, then test: change x by 100, then change x by −250. Where is Dot?
  3. Build the thermometer program on the right.
  4. Predict the LAST number it says. Then click the flag.

Math Inquirers P6 • Notice it. Test it. Explain why.

Minutes 10 to 15. Screen-share Scratch for 1 minute: show the x number under the stage as you drag the sprite left and right. "The stage is a number line. The middle is 0. Left of the middle is negative." Then children work in pairs (breakout rooms online), each on their own computer. Step 2: Dot starts at 0, change x by 100 takes it to 100, change x by −250 takes it to −150. Step 3: make the variable live in your screen share: Variables, Make a Variable, type temp, OK (children copy you). Type negative numbers with the keyboard minus key, never by pasting from the slide. There is no "decrease" block: to go down you change by a negative number. Step 4: they must write the prediction on the whiteboard BEFORE clicking. The program says 2, −1, −4, −7, −10, −13. Early finishers: add "if temp < 0 then say Below zero!" inside the loop, or make Dot glide to x = temp × 10 each time so it walks along the stage. Optional Python version (same program, for children who know Python): temp = 5 | for hour in range(6): | temp = temp + (-3) | print(temp) Output: 2, -1, -4, -7, -10, -13 (one per line).
