Key idea: core and growth

Repeating: find the core. Count in its size to see where each core ends. Then count on.

Growing: find what is added each time. Keep the table going, to find a far number or to work backwards.

Math Inquirers Level 1 Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Saying 3 more sticks each time because one triangle needs 3; ask them to point to the shared side. (2) Thinking the 30th shape is a circle because 30 starts with 3. (3) Q4: sharing 15 sticks into 3s to get 5 triangles; ask them to keep the table going instead. (4) Q2: drawing all 30 shapes; praise it, then ask for a quicker way.
