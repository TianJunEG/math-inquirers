Repeating patterns: find the core

red, blue, blue, red, blue, blue, red, blue, blue …

The core is red, blue, blue. It has 3 shapes.

What colour is the 9th? The 20th?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Worked example 1. Model it, then let children try. Answer: 9th is blue (3rd of core). Every 3rd bead ends a core: count 3, 6, 9, 12, 15, 18. The 18th ends a core, the 19th is red and the 20th is blue.
