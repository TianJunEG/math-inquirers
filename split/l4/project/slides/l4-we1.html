Worked example: the 20th bead

red, blue, blue, red, blue, blue … What colour is the 20th bead?

Step 1. The core has 3 beads, so count in 3s: 3, 6, 9, 12, 15, 18.

Step 2. 18 is a 3s number, so the 18th bead ends a core: blue.

Step 3. Start the core again: 19th red, 20th blue.

Step 4. Check: the 21st ends the next core (21 is a 3s number). 19 red, 20 blue, 21 blue ✓

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Click through the steps; ask the group to predict each one first. Count in 3s on fingers together and stop before passing 20. Think-aloud: "The core has 3 beads, so I count in 3s: 3, 6, 9, 12, 15, 18. The next one, 21, is too far. So the 18th bead is the end of a core, a blue bead. Then I start the core again: 19 is red, 20 is blue." Common mistake: starting the core again at 20 and saying red. Point to 18, 19, 20 on a number strip.
