Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Own paper, shown only to the tutor. a) 3, 6, 9, 12: the 12th is blue and ends a core; 13th red, 14th blue. b) 21 is a 3s number, so the 21st ends a core; the 22nd starts again: red. c) The core has 4 (cat, dog, dog, fish), so count in 4s: 4, 8. The 8th is fish; 9th cat, 10th dog. Ask a child to explain c: "Why did you count in 4s this time?"
