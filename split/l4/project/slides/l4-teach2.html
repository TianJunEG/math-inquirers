Growing patterns: what is added?

Make squares in a row with sticks. How many sticks does each new square need?

1 square: 4 sticks

2 squares: 7 sticks

3 squares: 10 sticks

Each new square shares a side with the one before. It needs only 3 new sticks.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Teach. Build it with real sticks if you can. Click to show 1, 2 and 3 squares; the gold sticks are the new ones. Ask before click 4: "Why only 3 new sticks, not 4?" Let a child point to the shared side. Then fill the table and say the rule. Think-aloud: "One square needs 4 sticks. When I add a square, it shares a side with the last one, so I only need 3 new sticks. 4, 7, 10, 13, 16. The rule is add 3." The worksheet uses triangles, so do not do triangles here.
