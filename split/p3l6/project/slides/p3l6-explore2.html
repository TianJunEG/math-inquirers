Explore: talk about it

1. How many 18 pieces fit exactly on 12?

2. Which is bigger, 16 or 18? Why?

3. Can eighths cover 13 exactly?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 15 to 25. Gather the pairs. Answers: 1) 4, so 1/2 = 4/8. 2) 1/6: the same whole is cut into fewer parts, so each part is bigger. 3) No. 2 eighths are too small and 3 eighths are too big. Sixths and twelfths can (2/6 and 4/12). Ask: "What other pieces line up exactly?" Collect a list: 1/2 = 2/4 = 3/6 = 4/8 = 6/12, 1/3 = 2/6 = 4/12, 1/4 = 2/8 = 3/12, 2/3 = 4/6 = 8/12, 3/4 = 6/8 = 9/12.
