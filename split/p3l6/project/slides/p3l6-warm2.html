Math Inquirers P3 Holiday Program • Notice it. Test it. Explain why.

Minutes 5 to 10. Whiteboards, then click. Ask for a reason each time. Answers: 1) 4. 2) 1/3: the whole is cut into fewer pieces, so each piece is bigger. 3) 5. 4) 6/9: we add the ninths; the bottom number stays 9. 5) 3/5: one whole is 5/5, and 5/5 − 2/5 = 3/5. Watch for children who write 6/18 for question 4: we come back to this mistake later.
