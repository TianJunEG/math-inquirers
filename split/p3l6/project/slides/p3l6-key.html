Key idea: make the parts the same size

To compare or add fractions, the parts must be the same size. Use the wall, or change one fraction to an equal fraction with the same bottom number.

When we add, we add the top numbers. The bottom number (the size of the parts) stays the same.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Adding the bottom numbers as well as the top numbers (1/3 + 1/3 = 2/6, or 1/4 + 1/8 = 2/12). (2) Thinking 1/8 is bigger than 1/6 because 8 is bigger than 6. (3) Comparing or adding fractions with different-sized parts without changing one first (1/4 + 3/8 = 4/8).
