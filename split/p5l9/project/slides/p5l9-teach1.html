Step 1. Each new square shares a side with the one before, so it adds only 3 sticks (the teal ones), not 4.

Step 2. Start with the first square's 4 sticks, or: 1 stick, then 3 for every square. Rule in words: sticks = 3 × figure number + 1

Step 3. Check the rule on figures 1, 2 AND 3: 3 × 1 + 1 = 4, 3 × 2 + 1 = 7, 3 × 3 + 1 = 10 ✓

Figure 25: 3 × 25 + 1 = 76 sticks. No drawing needed!

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Teach. Children build the three figures with toothpicks. Ask first: "How many sticks in figure 4? Figure 25?" Click the table row. Look at the picture: the teal sticks are the 3 new ones each time. Think-aloud: "Figure 2 is not 2 times figure 1 (8): the middle side is shared, so we save a stick. Each new square adds 3. I start with 1 stick and add 3 for each square: 3 times the figure number, plus the 1 extra." Then check the rule on three figures, not one. Trap to name: 25 lots of 3 plus 4 would be 79 (wrong), because the first square already counts its 4 sticks. The rule 3 × 25 + 1 = 76 is safe.
