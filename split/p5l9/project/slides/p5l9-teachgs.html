Math Inquirers Level 5 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q3). Start with a guess that is easy to check: half and half, 6 and 6 = $30. Too much by $1. Ask: "Which way do we change it?" A teh costs less, so we need more teh and fewer kopi. Each swap (one kopi becomes one teh) takes $1 off. One swap: 7 teh, 5 kopi = $29. Compare a random guess of 2 and 10 (way too much): a table that you CHANGE using what the last row told you finds the answer in 3 or 4 rows. Always check both facts: number of drinks AND the total.
