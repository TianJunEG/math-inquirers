Think harder: A rule from examples

Tool: Make a table

A machine uses the sign ★ for a rule. 2 ★ 3 = 8, 4 ★ 1 = 8, 5 ★ 2 = 15, 3 ★ 3 = 12.

(a) Find 6 ★ 4.

(b) Find the number x so that x ★ 3 = 28.

(a) 30.

(b) 7.

ADDED ITEM op (a slide-only addition for the skill gap "A rule from examples"; it is not in the printed workbook). TOOL: Make a table. SAY: Make a table of the pairs. Look at what happens to the first number in each example. Try a rule, then test it on all four. ASK: Does your rule work for all four examples? Why is one example not enough? LISTEN FOR: Rule: first number x (second number + 1). Listen for children testing a guess on every example and dropping it if it fails (Guess and check inside the table). Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: (a) 30. (b) 7. WHY: The rule is a x (b + 1): 2 × 4 = 8, 4 × 2 = 8, 5 × 3 = 15, 3 × 4 = 12. So 6 × 5 = 30. For x ★ 3: x times 4 = 28, so x = 7. SAME SKILL, NEW NUMBERS (tutor bank, say it aloud or write it on the board): A new machine: 1 ● 4 = 7, 2 ● 5 = 11, 3 ● 2 = 11, 5 ● 1 = 16. Find 4 ● 6. Answer: 18 (the rule is 3 x the first number + the second number).
