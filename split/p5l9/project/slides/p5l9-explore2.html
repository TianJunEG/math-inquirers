GO FURTHER: A SECOND WHAT-IF (OPTIONAL, IF YOU FINISH EARLY)

Find a quick rule for the number of high fives for ANY number of children. Use it for our group of 8, for a class of 30 and for 12 children.

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Minutes 21.5 to 25.5. Pencils down: gather the pairs. Answers: 1) 5 children: 10. 6 children: 15. 2) Table 2, 3, 4, 5, 6 children: 1, 3, 6, 10, 15. The jumps are 2, 3, 4, 5: a new child high-fives everyone already there, so the 4th child adds 3, the 5th adds 4 and so on (the 6th child adds 5). Go further what-if, not asked together: 8 children 28, and 30 children: each high-fives 29 others, 30 × 29 = 870, but every high five is counted twice (once by each child), so 870 ÷ 2 = 435. Do not push for this if nobody finds it; it returns on the Go further page. Note the jumps 2, 3, 4, 5 … grow each time; today we mostly study patterns that grow by the SAME amount each time. TWO questions together only (about a minute each), then move on. GO FURTHER what-if (open to every pair as soon as it has finished; nobody waits): 8 children: 28. 30 children: 435. 12 children: 66. With n children each high-fives (n − 1) others, but every high five is counted twice, so the number is n × (n − 1) ÷ 2. For 12 children: 12 × 11 ÷ 2 = 66. The table 1, 3, 6, 10, 15, 21 … also works.
