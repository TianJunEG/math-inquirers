1. How many high fives for 5 children? For 8? How did you get it?

2. What does the table do? What does each new child add?

3. Class of 30: is there a quick way?

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Minutes 15 to 25. Gather pairs. Answers: 1) 5 children: 10. 8 children: 28. 2) Table 2, 3, 4, 5, 6, 7, 8 children: 1, 3, 6, 10, 15, 21, 28. The jumps are 2, 3, 4, 5, 6, 7: a new child high-fives everyone already there, so the 4th child adds 3, the 5th adds 4 and so on (the 8th child adds 7). 3) 30 children: each high-fives 29 others, 30 × 29 = 870, but every high five is counted twice (once by each child), so 870 ÷ 2 = 435. Do not push for this if nobody finds it; it returns in Challenge ideas. Note the jumps 2, 3, 4, 5 … grow each time; today we mostly study patterns that grow by the SAME amount each time.
