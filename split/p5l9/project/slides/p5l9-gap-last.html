Think harder: Last digits of products

Tool: Spot the pattern

(a) Multiply 7 by itself 30 times: 7 × 7 × 7 x ... with 30 sevens. What is the last digit of the answer?

(b) Multiply 4 by itself 25 times. What is the last digit of the answer?

(a) 9.

(b) 4.

ADDED ITEM last (a slide-only addition for the skill gap "Last digits of products"; it is not in the printed workbook). TOOL: Spot the pattern. SAY: Only the last digit matters, so keep only the last digit each time. Write the last digit after 1 seven, 2 sevens, 3 sevens, 4 sevens, and carry on. ASK: When does the list of last digits start to repeat? How long is the cycle, and where does 30 land in it? LISTEN FOR: Sevens: 7, 9, 3, 1, then repeats (cycle of 4). 30 = 7 × 4 + 2, so the 2nd in the cycle: 9. Fours: 4, 6, 4, 6 (cycle of 2); 25 is odd, so 4. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: (a) 9. (b) 4. WHY: Last digits of 7, 7x7, ... are 7, 9, 3, 1, 7, 9, 3, 1, ... 30 mod 4 = 2, so the last digit is 9. Fours: 4, 6, 4, 6, ... 25 is an odd position, so 4. SAME SKILL, NEW NUMBERS (tutor bank, say it aloud or write it on the board): Multiply 2 by itself 22 times. What is the last digit? Answer: 4 (the cycle is 2, 4, 8, 6 and 22 mod 4 = 2).
