Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Optional, if you finish early (no clock time): show it while some pairs are working or have finished, or use it live as an extra warm-up or tutor-bank question; never at a fixed minute, and it never takes time from the plan. ADDED ITEM gaps (a slide-only addition for the skill gap "The gap of the gaps"; it is not in the printed workbook). TOOL: Make a table. SAY: Make a table with 3 columns: the tower number, the blocks, and the gap. Then add a fourth column for the gap of the gaps. ASK: What is the gap going to be between Tower 5 and Tower 6? Between Tower 9 and Tower 10? LISTEN FOR: Gaps 1, 3, 5, 7, 9, 11, 13, 15, 17. Listen for a table that keeps the pattern going row by row. Early finishers may notice each tower is a square number plus 2. Everyone writes the answer on their own paper, then say the answer together on three, then click the answer box. Nobody holds anything up, nobody is marked, and passing is always fine. ANSWER: (a) The gaps are 1, 3, 5, 7. They go up by 2 each time. (b) 51 blocks. (c) 83 blocks. WHY: Tower 6: 18 + 9 = 27. Tower 7: 27 + 11 = 38. Tower 8: 38 + 13 = 51. Tower 9: 51 + 15 = 66. Tower 10: 66 + 17 = 83. Pattern check: Tower n has (n - 1) × (n - 1) + 2 blocks, so Tower 10 is 9 × 9 + 2 = 83. SAME SKILL, NEW NUMBERS (tutor bank, say it aloud or write it on the board): Tower 1 has 1 block, Tower 2 has 2, Tower 3 has 5, Tower 4 has 10. The gaps go up by 2 each time. How many blocks in Tower 7? Answer: 37.
