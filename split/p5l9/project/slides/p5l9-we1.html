Working backwards: which figure?

Matchstick squares: sticks = 3 × figure number + 1. Which figure uses 61 sticks?

Step 1. Undo the last step first: 61 − 1 = 60

Step 2. Undo the times 3: 60 ÷ 3 = 20. Check forwards: 3 × 20 + 1 = 61 ✓

Math Inquirers P5 Holiday Program • Notice it. Test it. Explain why.

Worked example: backwards. Children first say what the machine does going forwards: times 3, then plus 1. Going backwards we undo in reverse order: the last step first. Click step 1, then step 2. Always check by going forward again. Ask: "What if the answer was 62 sticks?" (62 − 1 = 61, 61 ÷ 3 is not whole, so no figure uses exactly 62 sticks.) This is Q1c and Q3c on the worksheet.
