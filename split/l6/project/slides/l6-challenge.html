Go further

1. You have one 5¢, one 10¢, one 20¢ and one 50¢ coin. How many different amounts can you make using any of them? What if you also had a $1 coin (100¢)?

2. A sweet costs 15¢ and a biscuit costs 20¢. Ben spends exactly 90¢ and buys some of each. How many sweets and biscuits does he buy?

Make up your own

3. Make up your own coin puzzle that has exactly ONE answer (for example: "exactly 3 coins that make 35¢"). Write it, swap with a partner and check their answer by listing every possibility.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

For any pair that chooses Go further. Use it as a pair choice, or with volunteers in talk time (never call a child by name). Ask for the reason every time. Q3 is open: there is no single right answer, so ask children to check each other's work. Answers: 1) 15 different amounts: with 3 coins there are 7, and the 50¢ coin doubles that and adds one more. With a $1 coin as well there are 31: each new coin doubles the amounts and adds one more. 2) 2 sweets and 3 biscuits. 3) Open. A good puzzle has exactly one way. Example: 35¢ with exactly 3 coins from 5¢, 10¢, 20¢ and 50¢ has only 20¢ + 10¢ + 5¢. Check by listing every set of 3 coins.
