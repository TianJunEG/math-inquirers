Dollars: notes and $1 coins

A game costs $38. Pay exactly with the fewest notes and coins.

Step 1. Biggest first. $50 is too much. Use $10 notes: $10, $20, $30.

Step 2. $8 is left. $5 → $35. $2 → $37. $1 → $38.

$10 + $10 + $10 + $5 + $2 + $1 = $38 (6 pieces of money)

Math Inquirers Level 1 Holiday Program • Notice it. Test it. Explain why.

Optional: dollars are now Think harder T5. Hold up play notes: "These are dollars, not cents. Look for the $ sign." Same idea as coins: biggest note that is not too much, then work down, then count on to check: 10, 20, 30, 35, 37, 38. Point out there is no $20 note, so $20 is two $10 notes.
