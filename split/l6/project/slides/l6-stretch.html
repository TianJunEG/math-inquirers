For any pair that chooses to try more. These are the same four questions as Think harder T1 to T4 in the workbook (the labels match). Answers: T1) 2 sets: 50¢ + 10¢ + 5¢ + 5¢, and 20¢ + 20¢ + 20¢ + 10¢. T2) Three 10¢ and three 20¢ (30 + 60 = 90). T3) 3 coins (20¢ + 20¢ + 5¢) T4) 6 ways: 20+10; 20+5+5; 10+10+10; 10+10+5+5; 10+5+5+5+5; six 5¢. Start with the biggest coin and work down.
