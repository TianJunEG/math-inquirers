33–35 MIN

Key idea: work in order

Start with the biggest coin and work down. Use a table so you do not repeat a way.

Same coins in a different order count as one way.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 33 to 35. Say the key idea together. Common mistakes to watch for during the worksheet: (1) Listing the same way twice in a different order (10+5+5 and 5+10+5). (2) Choosing many small coins instead of looking for the fewest. (3) Stopping at the first set in Q4 instead of checking for all of them.
