Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 72 to 80. Pairs talk for 2 minutes. Then ask for volunteers first ("Who would like to share?"), never call a child by name to answer, and say that passing is always fine. No tallies and no rankings. Praise the reasons, not only the answers.
