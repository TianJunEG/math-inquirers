Number chains: add the two before

Example: 1, 3, 4, 7, 11 (1 + 3 = 4, 3 + 4 = 7, 4 + 7 = 11)

Work backwards: __, __, 9, 15, __

15 − 9 = 6: the 2nd number

9 − 6 = 3: the 1st number

9 + 15 = 24: the 5th number

3, 6, 9, 15, 24

Guess and check: 2, __, __, 16, __

Try 5: 2, 5, 7, 12. Too small.

Try 8: 2, 8, 10, 18. Too big.

Try 7: 2, 7, 9, 16 ✓

2, 7, 9, 16, 25

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Teach before worksheet page 2 (Q7). Read the example aloud. Left: when two numbers next to each other are known, work backwards by taking away. Right: when the gaps are in the middle, guess the 2nd number and test it, then adjust: 12 was too small and 18 too big, so the answer is in between. Ask: "When I add 1 to my guess, how much does the 4th number go up?" (by 2, because the guess is used twice). That helps strong children find it in one step.
