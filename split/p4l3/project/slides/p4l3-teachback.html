Teach before worksheet page 2 (Q4). Only two methods are taught before page 2 (this one and the bar model); the number trick and the chain are OPTIONAL if time. Strategy: WORK BACKWARDS. Start at the END. Each step is undone with the opposite operation: × and ÷ undo each other, + and − undo each other. Ask before each click: "What was the last thing the machine did? How do we undo it?" Watch for children who take away 6 again instead of adding 6. Always check by going forwards.
