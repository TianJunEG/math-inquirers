Opposite faces add up to 7. The net shows 6, 2 and 3.

a Below the 3. Which number is opposite the 6?

1

b Right of the 3. Which number is opposite the 2?

5

c The last square. Which number is opposite the 3?

4

Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Whiteboards, then click. The ends of the vertical line of 3 (6, 3, ?) are opposite, so the square below the 3 is 1 (6 + 1 = 7). The horizontal row is 2, 3, ?, ?: the 2 and the square two to its right are opposite, so that is 5 (2 + 5 = 7). The last square is the end of the row, opposite the 3: 4 (3 + 4 = 7). Check: 1, 2, 3, 4, 5, 6 all appear once.
