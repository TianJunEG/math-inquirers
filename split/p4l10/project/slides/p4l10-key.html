Math Inquirers P4 Holiday Program • Notice it. Test it. Explain why.

Say the key idea together. Common mistakes to watch for during the worksheet: (1) Guessing at random instead of using a table, so each try does not tell them whether to go up or down. (2) Working backwards but doing the same operation again (taking away 4 instead of adding 4), or undoing the steps in the wrong order. (3) Queues: adding the two positions (7th and 12th makes 19) and counting the person twice; logic puzzles: stopping before every clue has been used.
