Two steps: undo in reverse

I add 5, then I take away 3. I get 9.

Go back: undo take away 3 first (9 + 3 = 12), then undo add 5 (12 − 5).

What is my number?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Worked example 2. Ask children to explain each step in their own words. Draw the story as a line: start → add 5 → 12. To undo, go the other way: 12 − 5. Introduce the number machine table (IN and OUT). Answer: 7.
