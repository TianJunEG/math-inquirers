EXPLORE

  1. Lay two string loops so they overlap.
  2. Loop 1: buttons with 2 holes. Loop 2: red buttons.
  3. Sort all the buttons.
  4. Which buttons belong in the middle?

Picture: two overlapping string loops on a table with buttons inside: red buttons in one loop, 2-hole buttons in the other, and some in the middle.

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Minutes 10 to 15. Pairs work with the materials: Two loops of string, buttons or small objects, clue cards. Overlap two string loops. Sort a mixed set of buttons or objects by two rules and find the ones that belong in the middle. Online: Children sort objects from home by a rule shown on the slide and explain the rule on camera.
