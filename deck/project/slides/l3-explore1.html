Explore: what to do

EXPLORE

  1. Draw a row for each fruit.
  2. Put one counter for each child’s vote.
  3. Write the key: 1 counter = 1 child.
  4. Read the graph aloud: most, fewest, same, how many more.

Picture: a picture graph with five rows of fruit and one counter or smiley for each vote, next to a key box that says “1 face = 1 child”.
