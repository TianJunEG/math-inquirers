Key idea: the number machine

Number machine rule: add 2. IN 3 gives OUT 5. OUT 9 came from IN 7.

To go from OUT back to IN, do the opposite.

COMMON MISTAKES

• Adding again instead of undoing (12 + 5).

• Two steps: undoing in the wrong order.

• Queue question: giving 16 because Ali is counted twice.
