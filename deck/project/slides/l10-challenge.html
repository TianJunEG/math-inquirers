Challenge

1. Ali has some stickers. Ben has 4 more than Ali. Mei has 3 fewer than Ben. Together they have 29. How many does each have?

2. Make 70¢ using exactly 4 coins from 5¢, 10¢, 20¢ and 50¢. How many ways are there?

Math Inquirers Holiday Program • Notice it. Test it. Explain why.

Use as a pair challenge or in talk time. Ask for the reason every time. More are in the question bank. Answers: 1) Ali 8, Ben 12, Mei 9. 2) 2 ways: 50¢ + 10¢ + 5¢ + 5¢ and 20¢ + 20¢ + 20¢ + 10¢.
